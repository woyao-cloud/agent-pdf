# 第15章：Prompt 工程进阶

## 章节概述

本章深入讲解 Claude Code 的 Prompt 工程技巧，包括结构化 Prompt、系统提示词编写、上下文优化等高级技术。

## 学习目标

- 掌握结构化 Prompt 的设计方法
- 学会编写高效的系统提示词
- 理解上下文优化策略
- 能够通过 Prompt 精确控制输出

## 核心知识点

1. **结构化 Prompt**
   - 角色设定
   - 指令分层
   - 输出格式控制
   - 示例引导（Few-shot）

2. **系统提示词**
   - CLAUDE.md 的使用
   - 项目级指令配置
   - 全局 vs 局部提示词
   - 提示词版本管理

3. **上下文优化**
   - 上下文窗口管理
   - 关键信息优先策略
   - 冗余信息过滤
   - 长对话保持一致性

4. **高级技巧**
   - 思维链提示
   - 约束条件表达
   - 多轮迭代策略
   - 反馈循环设计

## 实战练习

为一个特定开发任务设计一套完整的 Prompt 体系，包括系统提示词和对话策略。
