# 第14章：Agent 与子任务编排

## 章节概述

本章介绍 Claude Code 的 Agent 系统和子任务编排能力，包括多 Agent 协作、任务分解、并行执行等高级工作流模式。

## 学习目标

- 理解 Claude Code 的 Agent 架构和类型
- 掌握任务分解和编排技巧
- 学会构建多 Agent 协作工作流
- 能够设计高效的并行执行策略

2. **任务分解策略**
   - 任务粒度控制

   - 任务依赖图构建

3. **并行执行编排**
   - 独立任务并行化
   - 结果聚合策略
   - 错误处理与重试
   - 执行进度监控

4. **工作流设计模式**
   - 流水线模式
   - 扇出/扇入模式
   - 监督式协作
   - 迭代优化循环
