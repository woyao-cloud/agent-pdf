# 《Claude Code 权威指南》续写设计文档

## 概述

本文档规划《Claude Code 权威指南：从入门到精通》第6-26章的续写方案。目前已完成的第1-5章为大纲骨架风格，后续章节保持统一模板和风格。

## 写作策略

- **顺序**：按 README 目录从第6章依次写到第26章
- **风格**：保持与第1-5章一致的大纲骨架风格（每章约1-2KB）
- **节奏**：一次性完所有章节，按 Part 分组输出，每完成一个 Part 做阶段性检查

## 章节模板

每章固定结构：

```
# 第N章：标题
## 章节概述 — 1段话说明本章内容
## 学习目标 — 4-6条可衡量的目标
## 核心知识点 — 3-6个主题，每个主题下列3-5个要点
## 实战练习 — 1个相关的练习建议
## 本章小结 — 关键要点回顾
## 思考题 — 2-3个引导性问题
```

## 章节内容规划

### Part02 核心技能篇（第6-8章）

**第6章：代码编写与修改**
- 核心主题：生成新代码、修改现有代码、代码补全与建议、批量修改策略
- 关键场景：从自然语言描述生成函数、修改既有实现、跨文件重构

**第7章：调试与问题排查**
- 核心主题：错误分析、运行时调试、日志分析、堆栈跟踪解读
- 关键场景：让 Claude 分析编译错误、定位 bug、建议修复方案

**第8章：测试驱动开发**
- 核心主题：TDD 流程（红-绿-重构）、测试生成、边界条件覆盖
- 关键场景：用 Claude 写测试用例、让 Claude 按测试实现功能、测试覆盖率分析

### Part03 中级应用篇（第9-12章）

**第9章：多文件协同开发**
- 核心主题：跨文件编辑、多文件上下文管理、依赖追踪、大规模修改策略
- 关键场景：同时修改多个文件实现一个功能、Claude 理解跨文件调用关系

**第10章：重构与代码优化**
- 核心主题：代码异味检测、重构模式提取、性能优化建议、技术债务管理
- 关键场景：使用 Claude 识别需要重构的代码、提取公共方法、优化算法

**第11章：文档生成与维护**
- 核心主题：README 生成、API 文档、代码注释优化、架构文档维护
- 关键场景：让 Claude 分析代码库并生成文档、保持文档同步更新

**第12章：正则表达式与文本处理**
- 核心主题：正则表达式生成与调试、批量文本转换、日志解析、数据提取
- 关键场景：用自然语言描述需求让 Claude 写正则、大规模文本处理任务

### Part04 高级技巧篇（第13-16章）

**第13章：复杂项目架构设计**
- 核心主题：用 Claude 做架构决策、系统设计讨论、技术选型分析、架构文档编写
- 关键场景：向 Claude 描述需求进行架构设计、多方案对比评估

**第14章：Agent 与子任务编排**
- 核心主题：多 Agent 协作、任务分解策略、并行执行编排、Agent 类型选择
- 关键场景：设置子任务让多个 Agent 并行工作、复杂任务的拆解与监督

**第15章：Prompt 工程进阶**
- 核心主题：结构化 Prompt、系统提示词编写、上下文优化、输出控制
- 关键场景：编写高效 system prompt、通过 Prompt 控制输出格式和质量、CLAUDE.md 的使用

**第16章：MCP 服务集成与 Skill 工作机制**
- 核心主题：MCP 协议、服务配置与集成、Skill 的创建与复用、Plugin 机制
- 关键场景：集成外部 MCP 服务、编写自定义 Skill、Plugin 开发基础

### Part05 项目实战篇（第17-23章）

**第17章：CLI 工具开发**
- 用 Claude Code 从零开发一个命令行工具（如文件处理工具）
- 覆盖：需求分析→代码生成→调试→发布全流程

**第18章：Web 后端服务开发**
- 用 Claude Code 开发一个 Web API 服务（FastAPI/Express）
- 覆盖：API 设计、路由、数据库操作、错误处理

**第19章：前端 React 项目开发**
- 用 Claude Code 开发 React 组件和页面
- 覆盖：组件设计、状态管理、样式、与后端联调

**第20章：全栈应用开发**
- 前后端联通的完整应用，展示 Claude Code 在全栈场景的协作能力
- 覆盖：全栈调试、数据流追踪、端到端功能实现

**第21章：创建 MCP 服务**
- 手把手用 Claude Code 创建一个 MCP 服务
- 覆盖：MCP 协议实现、工具注册、服务部署

**第22章：创建 Skill 实现工作扩展**
- 用 Claude Code 定义一个 Skill，扩展特定开发工作流
- 覆盖：Skill 文件结构、触发条件、上下文管理

**第23章：创建 Plugin 实现工作扩展**
- 开发一个 Claude Code Plugin
- 覆盖：Plugin API、生命周期、分发方式

### Part06 认证考试篇（第24-26章）

**第24章：考试概述与备考策略**
- 核心主题：考试结构、知识点权重、备考计划、资源推荐
- 覆盖：考试形式、评分标准、复习路线图

**第25章：模拟试题与解析**
- 核心主题：典型考题示例、答案详解、常见错误分析
- 覆盖：各知识领域模拟题、解题思路、易错点提醒

**第26章：考试技巧与注意事项**
- 核心主题：时间管理、答题策略、实操注意事项
- 覆盖：考试当天准备、时间分配策略、常见陷阱

## 质量准则

1. 每章保持统一模板结构
2. 每章约 1-2KB，大纲骨架风格
3. 知识点部分列出明确的子主题要点
4. 实战练习要具体可操作
5. 思考题要引导读者深入思考
