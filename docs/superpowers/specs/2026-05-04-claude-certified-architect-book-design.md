## 一、书籍概述

### 1.1 定位

- **书名**：《Claude Code 权威指南：从入门到精通》
- **副标题**：通过实际项目掌握 AI 辅助软件架构设计与开发
- **目标读者**：
  - 想通过 Claude Certified Architect 考试的开发者
  - 想深入掌握 Claude Code 的高级用户
  - 想学习 AI 辅助开发方法论的工程师

### 1.2 核心理念

> 以真实项目为载体，在实践中掌握 Claude Code 的使用技巧，同时覆盖 Claude Certified Architect 考试的所有知识点。

### 1.3 学习路径

- **主线一**：渐进式项目驱动（从单文件脚本 → 多文件项目 → 完整系统）
- **主线二**：知识精讲（穿插在项目中，覆盖所有考试要点）
