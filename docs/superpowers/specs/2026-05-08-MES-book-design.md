# MES书籍设计规范

> 创建日期：2026-05-08
> 目标：进阶实战型MES技术专著

## 一、书籍定位

**目标读者**：制造企业生产管理人员/IT人员、MES系统开发实施工程师、制造业数字化转型咨询顾问

**内容定位**：进阶实战 - 深入原理、包含源码与案例、偏重实施与开发

## 二、整体结构（六篇布局）

| 篇 | 主题 | 章节数 |
|---|---|---|
| 第一篇 | 概述与原理 | 4章 |
| 第二篇 | 核心模块详解 | 7章 |
| 第三篇 | 实施与开发 | 4章 |
| 第四篇 | 风险与优化 | 3章 |
| 第五篇 | 典型问题处理 | 2章 |
| 第六篇 | 开发者技能矩阵 | 2章 |

总计约 **22章**

## 三、篇章详细内容

### 第一篇：概述与原理（第1-4章）

#### 第1章 MES概述与解决的问题
- 制造系统层级（计划层→执行层→控制层）
- MES与ERP、SCADA、PLC的边界与协同
- MES核心价值：缩小计划与执行的gap

#### 第2章 MES实现原理
- 数据采集与实时监控
- 生产调度与工序管理
- 质量追溯与过程控制
- 典型架构模式（集中式/分布式/云原生）

#### 第3章 行业使用场景
- 离散制造（汽车、电子、机械）
- 流程制造（化工、医药、食品）
- 混合制造模式

#### 第4章 MES主流产品与生态
- 国际主流产品（西门子Opcenter、Rockwell FTPC等）
- 国内产品（鼎捷、易普优、芯翌等）
- 开源MES框架

#### 第8章 质量管理

#### 第9章 设备管理
