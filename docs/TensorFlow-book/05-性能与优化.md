## 2. 数据管道优化

### 2.1 tf.data 性能黄金法则

```python
# 黄金法则：并行 + 预取 + 缓存
dataset = (
    dataset
    .map(parse_fn, num_parallel_calls=tf.data.AUTOTUNE)  # 并行
    .cache()                                               # 缓存
    .batch(32, drop_remainder=True)                        # 定长 batch
    .prefetch(tf.data.AUTOTUNE)                            # 预取
)
```
- **`map(..., num_parallel_calls=tf.data.AUTOTUNE)`**：CPU 并行处理数据增强
- **`cache()`**：第一个 epoch 后，数据直接从内存读（避免重复 I/O）
- **`prefetch(tf.data.AUTOTUNE)`**：GPU 训练时 CPU 预加载下一批
- **`drop_remainder=True`**：避免最后一个 batch 大小不确定

### 2.2 常见数据瓶颈

| 问题 | 症状 | 解决方案 |
|------|------|---------|
| Python GIL | 单核 CPU 100% | 改用 `num_parallel_calls` |
| I/O 阻塞 | GPU 等数据 | 用 SSD、预取、cache |
| 图像解码慢 | CPU 高 | 预处理成 TFRecord / JPEG 2000 |
| 数据太大 | 内存不足 | 用 `tf.Example` + `lazy loading` |

### 2.3 使用 TFRecord

```python
def _bytes_feature(value):
    return tf.train.Feature(bytes_list=tf.train.BytesList(value=[value]))

def _int64_feature(value):
    return tf.train.Feature(int64_list=tf.train.Int64List(value=[value]))

def serialize_example(image, label):
    feature = {
        'image': _bytes_feature(image.tobytes()),
        'label': _int64_feature(label),
    }
    example = tf.train.Example(features=tf.train.Features(feature=feature))
    return example.SerializeToString()

# 写入
writer = tf.io.TFRecordWriter('train.tfrecord')
for image, label in dataset:
    writer.write(serialize_example(image, label))
writer.close()

# 读取
raw_dataset = tf.data.TFRecordDataset('train.tfrecord')
```

## 3. GPU 训练优化

### 3.1 混合精度训练

**原理**：用 float16（半精度）做矩阵运算，float32 做梯度累积和更新。

```python
# 开启混合精度
from tensorflow.keras import mixed_precision
mixed_precision.set_global_policy('mixed_float16')

# 或在策略中设置
policy = mixed_precision.Policy('mixed_float16')
mixed_precision.set_global_policy(policy)

# 验证
print(mixed_precision.global_policy())  # <Policy "mixed_float16">
```

**为什么有效**：
- 矩阵运算速度：float16 比 float32 快 2-8 倍（Tensor Core）
- 显存占用：减少 50%，可以跑更大的模型或更大的 batch

**必须注意**：
1. 损失缩放（Loss Scaling）：防止梯度 underflow
2. 某些算子自动用 float32（如 Softmax、LayerNorm）

```python
# 优化器使用动态损失缩放
optimizer = tf.keras.optimizers.Adam(learning_rate=1e-3)
optimizer = mixed_precision.LossScaleOptimizer(optimizer)
```

## 4. 分布式训练

### 4.1 单机多卡：MirroredStrategy

```python
strategy = tf.distribute.MirroredStrategy()
print(f"GPU 数量: {strategy.num_replicas}")

with strategy.scope():
    model = create_model()  # 所有 GPU 上模型自动复制
    model.compile(optimizer='adam', loss='sparse_categorical_crossentropy')

model.fit(dataset, epochs=10)
```

**工作原理**：
- 所有 GPU 同步更新同一组变量
- 梯度在所有 GPU 上汇总（All-Reduce）
- 每个 GPU 处理不同的 batch

### 4.2 多机训练：MultiWorkerMirroredStrategy

```python
# machine_config.json
{
    "cluster": {
        "worker": ["host1:port", "host2:port"]
    },
    "task": {"type": "worker", "index": 0}
}
```

```python
os.environ['TF_CONFIG'] = json.dumps(machine_config)
strategy = tf.distribute.MultiWorkerMirroredStrategy()

with strategy.scope():
    model = create_model()
    model.compile(...)
```

> ⚠️ **陷阱**：多机训练的网络拓扑对性能影响巨大。同一个交换机下的机器用 nccl 通信，跨交换机用 gloo。确保 NCCL 库安装正确。

### 4.3 TPU 训练

```python
# TPU 策略
resolver = tf.distribute.cluster_resolver.TPUClusterResolver()
tf.config.experimental_connect_to_cluster(resolver)
tf.tpu.experimental.initialize_tpu_system(resolver)
strategy = tf.distribute.TPUStrategy(resolver)

with strategy.scope():
    model = create_model()
```

### 4.4 选择策略

| 场景 | 策略 | 配置要点 |
|------|------|---------|
| 单机 1-4 GPU | MirroredStrategy | 默认 NCCL |
| 单机 >4 GPU | MirroredStrategy + 梯度聚合 | 考虑 Horovod |
| 多机多卡 | MultiWorkerMirroredStrategy | TF_CONFIG + NCCL/Gloo |
| TPU | TPUStrategy | TPU 地址正确 |
| 超大规模 | 考虑 Mesh TensorFlow / GSPMD | - |

### 5.3 知识蒸馏

```python
# Teacher 模型（已训练）
teacher = load_teacher_model()

# Student 模型（小模型）
student = create_small_model()

# 蒸馏损失
class DistillationLoss(tf.keras.losses.Loss):
    def __init__(self, temperature=4.0):
        super().__init__()
        self.temperature = temperature
    
    def call(self, y_true, y_pred):
        soft_teacher = tf.nn.softmax(teacher(y_pred) / self.temperature)
        soft_student = tf.nn.softmax(y_pred / self.temperature)
        return tf.keras.losses.categorical_crossentropy(soft_teacher, soft_student)
```

## 6. 性能 checklist

```
每次训练前检查清单：
□ 数据管线：prefetch( AUTOTUNE ) + cache()
□ batch size：尽量大（GPU 显存允许的极限）
□ 混合精度：开启 mixed_float16
□ XLA：@tf.function( jit_compile=True )
□ 显存增长：set_memory_growth=True
□ 监控：TensorBoard Profiler 看热点

分布式训练额外检查：
□ NCCL 安装：import tensorflow as tf; print(tf.config.list_physical_devices('COMM_COLL'))
□ TF_CONFIG 正确配置
□ 所有机器网络可达
□ 数据不重复（每个 worker 处理不同数据）
```
