## 1. SavedModel 核心

### 1.1 什么是 SavedModel

SavedModel 是 TensorFlow 的**通用模型交换格式**：
- 包含模型结构（计算图）
- 包含权重（checkpoint）
- 包含签名（signatures）——定义输入输出接口

```
my_model/
├── assets/
├── variables/
│   ├── variables.data-00000-of-00001
│   └── variables.index
└── saved_model.pb  ← 核心文件
```

### 1.2 导出 SavedModel

```python
# Keras 方式（推荐）
model.save('exported_model')

# 指定签名（用于 Serving）
model.save('model_with_signatures', signatures={
    'serving_default': serving_function,
    'predict_batch': batch_predict_function
})

# 函数式模型的签名
model = create_model()
full_model = tf.function(lambda x: model(x))
full_model = full_model.get_concrete_function(
    tf.TensorSpec(shape=(None, 224, 224, 3), dtype=tf.float32)
)
model.save('model', signatures=full_model)
```

### 1.3 加载 SavedModel

```python
# 加载为 Keras 模型
model = tf.keras.models.load_model('exported_model')

# 加载为 Concrete Function（更底层，可获取签名列表）
imported = tf.saved_model.load('exported_model')
print(imported.signatures.keys())

# 调用签名
result = imported.signatures['serving_default'](x=input_tensor)
```

## 2. TF Serving

### 2.1 快速启动

```bash
# Docker 方式（推荐）
docker pull tensorflow/serving
docker run -p 8501:8501 \
    --mount type=bind,source=/path/to/model,target=/models/my_model \
    -e MODEL_NAME=my_model \
    tensorflow/serving

# 或本地编译
bazel build //tensorflow_serving/model_servers:tensorflow_model_server
```

### 2.2 gRPC API

```python
import grpc
import tensorflow as tf
from tensorflow_serving.apis import predict_pb2
from tensorflow_serving.apis import prediction_service_pb2_grpc

# 连接
channel = grpc.insecure_channel('localhost:8500')
stub = prediction_service_pb2_grpc.PredictionServiceStub(channel)

# 请求
request = predict_pb2.PredictRequest()
request.model_spec.name = 'my_model'
request.model_spec.signature_name = 'serving_default'
request.inputs['input_1'].CopyFrom(
    tf.make_tensor_proto(input_data, shape=input_data.shape))

# 响应
result = stub.Predict(request)
output = tf.make_ndarray(result.outputs['output_1'])
```

### 2.3 REST API

```python
import requests
import json

# 预测
response = requests.post(
    'http://localhost:8501/v1/models/my_model:predict',
    json={
        'signature_name': 'serving_default',
        'inputs': input_data.tolist()
    }
)
result = response.json()['outputs']

# 获取模型状态
response = requests.get('http://localhost:8501/v1/models/my_model')
print(response.json())
```

### 2.4 批处理

TF Serving 内置动态批处理：

```python
# 请求
request = predict_pb2.PredictRequest()
request.model_spec.name = 'my_model'
# TF Serving 会自动把多个请求合并成 batch
```

批处理配置（可在模型配置中调整）：
- max_batch_size：最大批大小
- batch_timeout_micros：等待超时
- num_batch_threads：批处理线程数

## 3. TFLite 端侧推理

### 3.1 转换流程

```python
# 1. 转换为 TFLite
converter = tf.lite.TFLiteConverter.from_keras_model(model)
converter.optimizations = [tf.lite.Optimize.DEFAULT]

# 2. 量化（可选）
converter.target_spec.supported_types = [tf.float16]

# 3. 转换
tflite_model = converter.convert()

# 4. 保存
with open('model.tflite', 'wb') as f:
    f.write(tflite_model)
```

## 5. TFX 端到端流水线

### 5.1 TFX 组件

```
ExampleGen → StatisticsGen → SchemaGen → ExampleValidator → 
Transform → Trainer → Tuner → Evaluator → InfraValidator → Pusher
```

```python
import tfx
from tfx.components import CsvExampleGen, StatisticsGen, SchemaGen
from tfx.orchestration import LocalDagRunner
from tfx.orchestration.kubeflow import KubeflowDagRunnerConfig

# 1. 数据入口
example_gen = CsvExampleGen(input_base='data/')

# 2. 统计
statistics = StatisticsGen(examples=example_gen.outputs['examples'])

# 3. 推演 Schema
schema = SchemaGen(statistics=statistics.outputs['statistics'])

# 4. 训练
trainer = Trainer(
    module_file='trainer.py',
    examples=example_gen.outputs['examples'],
    schema=schema.outputs['schema'],
    train_args=tfx.proto.TrainArgs(num_steps=10000),
    eval_args=tfx.proto.EvalArgs(num_steps=1000)
)

# 5. 评估
evaluator = Evaluator(
    model=trainer.outputs['model'],
    examples=example_gen.outputs['examples'],
    eval_config=eval_config
)

# 6. 部署
pusher = Pusher(
    model=trainer.outputs['model'],
    model_blessing=evaluator.outputs['blessing'],
    push_destination=tfx.proto.PushDestination(
        filesystem=tfx.proto.PushDestination.Filesystem(
            base_directory='serving_model/'
        )
    )
)
```

### 5.2 Kubeflow 部署

```python
# 配置 Kubeflow 流水线
from tfx.orchestration.kubeflow import KubeflowDagRunnerConfig

config = KubeflowDagRunnerConfig(
    kubeflow_metadata_config=kubeflow_metadata.mysql_metadata_connection_config(
        mysql_host='mysql',
        mysql_port=3306,
        database='mlpipeline',
    )
)

from tfx.orchestration import KubeflowDagRunner
runner = KubeflowDagRunner(config=config)
runner.run(pipeline)
```

### 5.3 Airflow 部署

```python

dag = AirflowDagRunner(
    AirflowPipelineConfig(
        schedule_interval='@daily',

dag >> 'my_pipeline_dag.py'
```

## 6. 部署 checklisk

```
部署前检查：
□ 模型导出为 SavedModel 格式
□ 测试过 .predict() 多次调用的内存泄漏
□ 确认签名名称正确（serving_default 或自定义）
□ 验证输入输出 shape 和 dtype
□ 检查模型版本目录格式正确

Serving 检查：
□ 模型放在 MODEL_PATH 下，格式正确
□ gRPC/REST 端口可访问
□ 动态批处理配置合理
□ 监控指标正常（请求延迟、错误率）

端侧检查：
□ 量化后精度可接受（<1% 下降）
□ 推理延迟满足要求
□ 内存占用 < 设备限制

TFX 检查：
□ 数据验证通过
□ 模型评估指标达标
□ Schema 正确
□ 可以复现训练流程
```
