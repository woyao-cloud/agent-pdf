# 第 8 章 开发者技能矩阵

> **本章导读**：TensorFlow 开发者需要什么技能？本章从低到高划分 5 个等级，列出每个等级的核心知识、工具链、实战要求，帮助你规划成长路径。

## 1. 技能等级概览

```
L1: 基础使用 ── 能跑通官方示例，改动简单参数
L2: 独立开发 ── 能从 0 训练模型，处理数据，优化简单场景
L3: 生产交付 ── 能独立完成模型开发→部署完整流程
L4: 性能优化 ── 能解决复杂性能问题，做大规模分布式训练
L5: 架构专家 ─能设计 ML 系统，制定技术选型，带团队落地
```

## 2. L1: 基础使用

### 2.1 核心知识

| 知识 | 掌握程度 |
|------|---------|
| Python 基础 | 熟练（list、dict、numpy、函数、类） |
| 机器学习基础 | 理解监督学习、损失函数、梯度下降 |
| TensorFlow 基础 | 知道 TF 是什么，能运行 Keras 示例 |
| 张量操作 | 知道 tf.Tensor 是什么，会 reshape / slice |

### 2.2 技能清单

```bash
# 必须会
- 安装 TensorFlow（pip / conda / Docker）
- 跑通 Keras MNIST/CIFAR 示例
- 理解 model.fit() / model.evaluate() / model.predict()
- 会用 TensorBoard 查看训练曲线
- 基本的 tf.data 数据加载
- 基本的 tf.GradientTape 用法
- 模型保存/加载（model.save / load_model）
```

### 2.3 实战要求

- 能用 Keras 训练一个图片分类模型（准确率 > 85%）
- 能用 TensorBoard 观察 loss 和 accuracy 曲线
- 能用预训练模型做迁移学习

### 2.4 推荐学习资源

- 官方 Keras Guide: https://keras. io/guides/
- 官方 TF Tutorial: https://www. tensorflow. org/tutorials

## 3. L2: 独立开发

### 3.1 核心知识

| 知识 | 掌握程度 |
|------|---------|
| 深度学习理论 | 理解 CNN / RNN / Transformer 原理 |
| 数据工程 | 熟练使用 tf.data 做预处理 |
| 模型构建 | 会用 Functional / Subclassing API |
| 训练调试 | 知道常见问题及解决方案 |
| GPU 使用 | 知道 GPU 环境配置和基础监控 |

### 3.2 技能清单

```bash
# 必须会
- 构建复杂模型（多输入/输出、共享层、条件分支）
- 使用 tf.data 构建高效数据管线
- 自定义训练循环
- 自定义层和自定义损失
- 数据增强和预处理
- 模型评估指标（Precision / Recall / F1 / AUC）
- GPU 环境配置（CUDA / cuDNN）

# 应该会
- 使用 TensorFlow Hub 加载预训练模型
- 基础调试（Eager 模式、打印中间值）
- 基础性能调优（prefetch、parallel）
- 基础模型压缩（量化）
```

### 3.3 实战要求

- 能独立完成图像/NLP/推荐系统的端到端开发
- 能构建高效数据管道（prefetch、cache、parallel）
- 能处理生产级别的数据（TFRecord、大文件）
- 能自定义训练逻辑（早停、模型检查点、学习率调度）

### 3.4 推荐学习资源

- 《Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow》
- 官方 tf.data 指南：https://www. tensorflow. org/guide/data
- 官方 Keras 教程：https://keras. io/examples

## 4. L3: 生产交付

### 4.1 核心知识

| 知识 | 掌握程度 |
|------|---------|
| 模型部署 | 掌握 SavedModel、TF Serving、TFLite |
| 性能优化 | 混合精度、分布式训练、模型压缩 |
| 生产系统 | 理解 MLOps、模型版本管理 |
| 监控运维 | 模型监控、数据漂移检测 |

### 4.2 技能清单

```bash
# 必须会
- 导出和优化 SavedModel
- 部署 TF Serving（Docker / K8s）
- 部署 TFLite（Android / iOS / 端侧）
- 混合精度训练
- 分布式训练（MirroredStrategy）
- 模型量化（动态范围 / 整型）
- 性能 Profiling（TensorBoard）
- 模型版本管理

# 应该会
- TFX 流水线
- TF Serving 批处理配置
- 模型部署后的监控
- 数据验证（TensorFlow Data Validation）
```

### 4.3 实战要求

- 能完成模型训练→优化→部署的完整链路
- 能处理高并发模型服务
- 能监控模型质量（延迟、吞吐、精度）
- 能处理 TFLite 部署的精度损失问题

## 5. L4: 性能优化

### 5.1 核心知识

| 知识 | 掌握程度 |
|------|---------|
| 分布式训练 | 多机多卡、TPU |
| 编译优化 | XLA、JIT |
| GPU 架构 | CUDA、显存优化 |
| 大模型训练 | 梯度 checkpoint、模型并行 |

### 5.2 技能清单

```bash
# 必须会
- 多机多卡分布式训练配置
- TPU 训练
- XLA 编译优化
- 梯度 checkpointing
- 模型并行（超大模型）
- 显存优化（混合精度、内存规划）
- 性能瓶颈分析（Profiler 深度使用）
- 自定义 XLA 算子

# 应该会
- Mesh TensorFlow / GSPMD
- 自定义 GPU 算子（CUDA）
- 编译器原理（LLVM）
```

### 5.3 实战要求

- 能配置 8+ GPU 分布式训练
- 能在 TPU 上完成训练
- 能解决复杂性能瓶颈
- 能分析 Profiler 报告并优化

## 6. L5: 架构专家

### 6.1 核心知识

| 知识 | 掌握程度 |
|------|---------|
| 系统架构 | 大规模 ML 系统设计 |
| 技术选型 | TensorFlow vs PyTorch vs JAX |
| 团队建设 | 制定开发规范、技术培训 |
| 前沿追踪 | 关注 TF 发展路线图 |

### 6.2 技能清单

```bash
# 必须会
- 设计端到端 ML 平台
- 制定 TensorFlow 开发规范
- 技术选型（框架、部署方案）
- 性能/成本权衡分析
- 团队代码审查
- 解决复杂技术问题

# 应该会
- 贡献 TensorFlow 源码
- 参与 TF RFC 讨论
- 发表技术博客/演讲
- 招聘和培养 ML 工程师
```

### 6.3 实战要求

- 能主导企业级 ML 平台建设
- 能制定技术路线图
- 能解决跨团队技术难题

## 7. 工具链总览

```bash
# 开发环境
- Python 3.10+
- TensorFlow 2.15+
- CUDA 12.x
- cuDNN 8.x
- Docker

# 训练工具
- TensorBoard (可视化)
- tf.estimator (高层 API，deprecated)
- TFX (流水线)
- TF-agents (强化学习)
- TFRS (推荐系统)

# 部署工具
- TF Serving (服务端)
- TFLite (端侧)
- TF.js (浏览器)
- TensorFlow Hub (模型市场)

# 调试工具
- tf.debugging
- tf.GradientTape
- TensorBoard Profiler

# 辅助工具
- Netron (模型可视化)
- Weights & Biases (实验跟踪)
- MLflow (ML lifecycle)
```

## 8. 面试考点（供参考）

### 8.1 基础题

- 解释 Eager Execution vs Graph Execution
- tf.gradientTape 工作原理
- Keras 三层 API 的区别
- 如何处理类别不均衡

### 8.2 中级题

- tf.data 性能优化技巧
- 混合精度训练原理
- 分布式训练策略
- SavedModel vs HDF5

### 8.3 高级题

- XLA 编译器优化原理
- 多机分布式训练的网络拓扑
- 大模型训练显存优化
- 模型服务性能调优
