## 1. 数值稳定性问题

### 1.1 梯度爆炸

**症状**：
- loss 变成 NaN 或 Inf
- 梯度值巨大（如 `nan` 或 `inf`）
- 权重更新后变成 NaN

**原因**：多层连乘导致梯度指数级增长

**解决方案**：

```python
# 1. 梯度裁剪
optimizer = tf.keras.optimizers.Adam(clipnorm=1.0)  # 全局裁剪
# 或
gradients = tape.gradient(loss, vars)
gradients = [(tf.clip_by_norm(g, 1.0)) for g in gradients]

# 2. 梯度正则化
gradients, _ = tf.clip_by_global_norm(gradients, clip_norm=1.0)

# 3. 降低学习率
optimizer = tf.keras.optimizers.Adam(1e-4)

# 4. 添加梯度噪声（可选）
noise = [tf.random.normal(tf.shape(g), stddev=0.01) for g in gradients]
gradients = [g + n for g, n in zip(gradients, noise)]
```

### 1.2 梯度消失

**症状**：
- loss 下降极慢
- 底层（靠近输入）梯度接近 0
- 深层网络训练不动

**原因**：激活函数导数 < 1，多层连乘导致梯度趋于 0

**解决方案**：

```python
# 1. 使用 ReLU 及其变体（梯度恒为 1）
model = tf.keras.Sequential([
    tf.keras.layers.Dense(64, activation='relu'),  # 不是 sigmoid/tanh
    ...
])

# 2. 残差连接
class ResidualBlock(tf.keras.layers.Layer):
    def call(self, x):
        return x + self.inner_block(x)  # 梯度直接传回

# 3. 归一化层（梯度更稳定）
# BatchNorm, LayerNorm, GroupNorm

# 4. 初始化方法
# He init for ReLU, Xavier for tanh
model = tf.keras.Sequential([
    tf.keras.layers.Dense(64, kernel_initializer='he_normal'),
])
```

### 1.3 数值溢出

**症状**：
- Softmax 输出变成 NaN
- Log(0) 产生 -Inf
- 指数运算溢出

**解决方案**：

```python
# 1. Softmax 用稳定实现
# TF 自带的是数值稳定的，但自定义实现要注意
def stable_softmax(x):
    exp_x = tf.exp(x - tf.reduce_max(x))  # 减去最大值防止溢出
    return exp_x / tf.reduce_sum(exp_x)

# 2. Log 避免 0
log_x = tf.math.log(tf.clip_by_value(x, 1e-8, 1e+8))

# 3. 损失函数用 tf.keras 内置（已处理数值稳定）
loss = tf.keras.losses.CategoricalCrossentropy(from_logits=False)
```

## 2. 内存问题

### 2.1 GPU OOM（Out Of Memory）

**常见原因**：

| 原因 | 解决方案 |
|------|---------|
| batch size 太大 | 减小 batch_size |
| 模型太大 | 梯度 checkpointing / 模型并行 |
| 中间张量太大 | 减少序列长度、图像分辨率 |
| 内存泄漏 | 检查是否有张量未释放 |
| 多个模型同时加载 | 按需加载，用完释放 |

**排错代码**：

```python
import gc

# 1. 检查显存使用
print(f"GPU Memory: {tf.config.experimental.get_memory_info('GPU:0')}")

# 2. 清理显存
del model
gc.collect()
tf.keras.backend.clear_session()  # 清理 Keras 缓存

# 3. 显存增长允许（默认）
gpus = tf.config.list_physical_devices('GPU')
for gpu in gpus:
    tf.config.experimental.set_memory_growth(gpu, True)
```

### 2.2 内存泄漏检测

```python
# 监控显存增长
import tracemalloc
tracemalloc.start()

# 训练多个 epoch
for epoch in range(10):
    model.fit(...)
    
    # 检查当前显存
    current, peak = tracemalloc.get_traced_memory()
    print(f"Epoch {epoch}: current={current/1024/1024:.1f}MB, peak={peak/1024/1024:.1f}MB")

tracemalloc.stop()
```

**常见泄漏源**：
- Python list 不断 append 但不清理
- Keras callback 保存 history 太大
- tf.function 重新 trace
- 全局变量引用模型

## 3. 训练问题

### 3.1 不收敛

**诊断流程**：

```
□ 损失不下降？
  ├─ 数据问题：检查 label 是否正确
  ├─ 学习率：尝试 10x 或 0.1x
  ├─ 初始化：He init vs Xavier
  ├─ 激活函数：尝试 ReLU
  └─ 模型结构：先跑通小模型
```

**修复代码**：

```python

model = tf.keras.Sequential([
    tf.keras.layers.Dense(10, activation='relu', input_shape=(100,)),
    tf.keras.layers.Dense(1)
])
model.compile(optimizer='adam', loss='mse')

# 2. 检查数据
```

### 4.3 常见错误速查

| 错误 | 原因 | 解决方案 |
|------|------|---------|
| `InvalidArgumentError` | shape 不匹配 | 检查 input_shape |
| `ResourceExhaustedError` | OOM | 减小 batch / 模型 |
| `ValueError` | 数据类型不对 | cast 到正确 dtype |
| `Op not found` | TFLite 不支持 | 检查 TF Lite op 列表 |
| `SavedModel error` | 签名格式错 | 检查 signature_name |

## 6. 小结

| 问题类别 | 常见症状 | 核心解决方案 |
|---------|---------|--------------|
| 数值稳定 | NaN / Inf | 梯度裁剪 + 数值稳定实现 |
| 内存 | OOM | batch、梯度 checkpoint、显存增长 |
| 训练 | 不收敛 | 数据检查 + LR 扫描 + 小模型先跑通 |
| 调试 | 奇怪行为 | Eager 模式 + Profiler + 打印 |
| 部署 | 延迟高 | XLA + TFLite 量化 + 批处理 |
