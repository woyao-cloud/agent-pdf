# 第8章 质量管理

质量管理是制造执行系统（MES）的核心模块之一，承担着确保产品质量、监控生产过程、追溯质量问题的重要职责。本章将详细讲解质量管理体系的构建、SPC统计过程控制、检验管理、质量追溯以及不良品处理等核心功能模块。

## 8.1 质量管理体系概述

### 8.1.1 质量管理体系框架

质量管理体系的建立需要遵循国际标准，并结合企业实际情况进行裁剪和实施。

**ISO 9001质量管理体系**是国际通用的质量管理标准，强调以客户为中心、领导作用、过程方法、持续改进等核心原则。在MES中的实施要点包括：建立质量方针和质量目标、制定质量手册和程序文件、实施内部审核和管理评审、建立纠正措施和预防措施机制。

**IATF 16949汽车行业质量管理标准**是在ISO 9001基础上针对汽车行业的特殊要求制定的，强调缺陷预防、减少变异和浪费。在MES中的实施要点包括：建立汽车行业特殊要求的质量管理流程、实施APQP（产品质量先期策划）和PPAP（生产件批准程序）、建立供应链质量管理机制、强调过程绩效监控和持续改进。

**ISO/TS 22163铁路行业质量管理体系**针对铁路行业的安全性和可靠性要求，建立从设计到运维的全生命周期质量管理。

### 8.1.2 质量控制点设置

质量控制点（Quality Control Point，QCP）是生产过程中需要进行质量检验或监控的关键工序点。

**关键工序**是指对产品质量有直接影响、不能轻易返工或返修的工序。例如：焊接工序、热处理工序、装配调试工序等。MES系统需要记录关键工序的操作人员、设备参数、原材料批次等完整信息。

**特殊工序**是指无法通过后续检验完全验证质量、过程参数直接影响产品质量的工序。例如：电镀、喷涂、注塑等。MES系统需要对特殊工序的过程参数进行实时监控和记录。

**不良品记录**包括：不良现象描述、不良数量、不良部位、产生工序、责任部门、原因分析等信息。不良品记录需要关联到具体的生产工单和批次。

## 8.2 SPC统计过程控制

SPC（Statistical Process Control，统计过程控制）是一种通过统计分析过程数据来监控和控制产品质量的管理方法。SPC的核心思想是"过程受控，减少变异"。

### 8.2.1 控制图原理

**正态分布基础**

产品质量特性通常服从正态分布（或者近似正态分布）。正态分布的概率密度函数为：

$$f(x) = \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$$

其中，$\mu$为均值，$\sigma$为标准差。正态分布具有以下重要性质：

- 约68.27%的数据落在$\mu \pm 1\sigma$范围内
- 约95.45%的数据落在$\mu \pm 2\sigma$范围内
- 约99.73%的数据落在$\mu \pm 3\sigma$范围内

**3σ原则**

控制图基于统计学中的3σ原理，即假设过程处于统计受控状态时，几乎所有（99.73%）的数据点都应落在$\mu \pm 3\sigma$的控制限内。如果有点超出控制限，则认为过程存在异常变异。

控制图的中心线（CL）通常设定为过程均值：

$$CL = \bar{X} = \frac{\sum_{i=1}^{n} X_i}{n}$$

上控制限（UCL）和下控制限（LCL）分别为：

$$UCL = \bar{X} + 3\sigma_{\bar{X}}$$

$$LCL = \bar{X} - 3\sigma_{\bar{X}}$$

### 8.2.2 控制图类型

根据数据类型和控制目的的不同，控制图可分为多种类型：

**X-bar图和R图（均值-极差控制图）**

X-bar图用于监控过程均值的变化，适用于计量型数据。R图用于监控过程变异（极差）的变化。

对于X-bar图，控制限计算公式为：

$$UCL_{\bar{X}} = \bar{\bar{X}} + A_2\bar{R}$$

$$LCL_{\bar{X}} = \bar{\bar{X}} - A_2\bar{R}$$

对于R图，控制限计算公式为：

$$UCL_R = D_4\bar{R}$$

$$LCL_R = D_3\bar{R}$$

其中，$\bar{\bar{X}}$为总均值，$\bar{R}$为平均极差，$A_2$、$D_3$、$D_4$为与子组大小n有关的系数。

| n | A2 | D3 | D4 |
|---|---|---|---|
| 2 | 1.880 | 0 | 3.267 |
| 3 | 1.023 | 0 | 2.574 |
| 4 | 0.729 | 0 | 2.282 |
| 5 | 0.577 | 0 | 2.114 |
| 6 | 0.483 | 0 | 2.004 |

**P图（不合格品率控制图）**

P图用于监控不合格品率，适用于计件型数据。控制限计算公式为：

$$UCL_p = \bar{p} + 3\sqrt{\frac{\bar{p}(1-\bar{p})}{n}}$$

$$LCL_p = \bar{p} - 3\sqrt{\frac{\bar{p}(1-\bar{p})}{n}}$$

其中，$\bar{p}$为平均不合格品率，n为样本大小。

**C图（缺陷数控制图）**

C图用于监控单位产品上的缺陷数，适用于计点型数据（如气泡、划痕等）。控制限计算公式为：

$$UCL_c = \bar{C} + 3\sqrt{\bar{C}}$$

$$LCL_c = \bar{C} - 3\sqrt{\bar{C}}$$

其中，$\bar{C}$为平均缺陷数。

### 8.2.3 过程能力指数

过程能力指数（Process Capability Index）是衡量过程满足规格要求能力的指标。

**Cp（过程能力指数）**

$$C_p = \frac{USL - LSL}{6\sigma}$$

其中，USL为规格上限，LSL为规格下限，$\sigma$为过程标准差。

Cp值解释：

- Cp ≥ 1.33：过程能力充足
- 1.00 ≤ Cp < 1.33：过程能力尚可
- 0.67 ≤ Cp < 1.00：过程能力不足
- Cp < 0.67：过程能力严重不足

**CPK（过程能力指数，考虑偏移）**

$$C_{PK} = \min\left(\frac{USL - \mu}{3\sigma}, \frac{\mu - LSL}{3\sigma}\right)$$

其中，$\mu$为过程均值。

**案例：过程能力分析**

某零件外径尺寸规格为10.00±0.05mm，测量25个子组、每组5个样本，计算得到：

- 总均值$\bar{\bar{X}}$ = 10.002mm
- 平均极差$\bar{R}$ = 0.012mm
- 查表得D2=2.326（n=5），则$\sigma = \bar{R}/D_2 = 0.012/2.326 = 0.00516$mm

计算过程能力：

$$C_p = \frac{10.05 - 9.95}{6 \times 0.00516} = \frac{0.1}{0.03096} = 3.23$$

$$C_{PK} = \min\left(\frac{10.05 - 10.002}{3 \times 0.00516}, \frac{10.002 - 9.95}{3 \times 0.00516}\right) = \min(3.10, 3.36) = 3.10$$

该过程过程能力充足（Cp=3.23, CPK=3.10），说明过程控制良好。

### 8.2.4 异常判异规则

控制图不仅用于监控过程是否在控制限内，还需要分析数据点的分布规律以发现潜在异常。常用的判异规则包括：

1. **点出界**：单个数据点超出控制限
2. **连续9点同侧**：连续9点在中心线同一侧
3. **连续6点递增或递减**：连续6点呈现单调趋势
4. **连续14点交替上下**：存在周期性变异
5. **连续3点中有2点在A区**：$\bar{X} > \mu + 2\sigma$或$\bar{X} < \mu - 2\sigma$
6. **连续5点中有4点在B区外**：$\bar{X} > \mu + \sigma$或$\bar{X} < \mu - \sigma$
7. **连续15点在C区**：过程变异过小，可能存在分层问题
8. **连续8点在C区外**：存在异常变异

## 8.3 检验管理

### 8.3.1 IPQC巡检

IPQC（In-Process Quality Control，过程质量控制）巡检是在生产过程中进行的巡回检验，目的是及时发现并纠正异常，防止不良品流入下道工序。

**巡检项目设置**包括：外观检验、尺寸检验、功能检验、关键特性检验等。每个巡检项目需要定义检验标准、检验方法、判定标准。

**巡检频率**根据产品重要性和工序风险程度确定。高风险工序可能需要每30分钟或每小时巡检一次，一般工序可每2-4小时巡检一次。

**不合格处理流程**：发现不合格时，应立即通知操作人员停止作业，标识隔离不合格品，填写不良记录，并启动不良品处理流程。

### 8.3.2 首件检验

首件检验（First Article Inspection，FAI）是对每批次、每班次、每台设备开始生产的第一件或前几件产品进行的全面检验。首件确认后方可开始批量生产。

首件检验要点：

1. **参数记录**：记录首件生产时的设备参数（温度、压力、速度等）、环境条件、原材料批次
2. **全面检验**：按照检验标准对首件进行全部项目的检验
3. **对比分析**：将首件参数与标准工艺参数进行对比，评估是否符合要求
4. **首件签章**：首件检验合格后，检验人员和生产人员签字确认，方可开始批量生产

### 8.3.3 成品检验

成品检验（FQC，Final Quality Control）是对已完成生产的成品进行的最终检验，确保出货产品符合客户要求和规格标准。

**抽检方案**：根据GB/T 2828.1（ISO 2859-1）正常检验一次抽样方案，确定抽检水平和AQL（Acceptable Quality Level，可接受质量水平）。例如：正常检验二级，抽样水平II，AQL=0.65。

**判定标准**：

- 严重缺陷（A类）：AQL=0，不允许存在
- 主要缺陷（B类）：AQL=0.65
- 次要缺陷（C类）：AQL=1.5

## 8.4 质量追溯

质量追溯是MES质量管理的重要功能，通过建立完整的信息链，实现从原材料到成品的全过程追踪，以及从成品到原材料的逆向追溯。

### 8.4.1 正向追溯

正向追溯（Forward Traceability）是从原材料到成品的追踪，记录每个物料在生产过程中的流转情况。

追溯信息包括：

- 原材料信息：批次号、供应商、检验状态、投入时间
- 加工信息：工序、设备、操作人员、参数、时间
- 检验信息：检验项目、结果、检验人员
- 成品信息：批次号、生产日期、数量、出货信息

### 8.4.2 逆向追溯

逆向追溯（Backward Traceability）是从成品追溯到原材料的逆向追踪，用于问题产品召回、质量问题分析等场景。

通过扫描成品序列号或批次号，可以快速查询：

- 该产品使用了哪些原材料批次
- 原材料在哪些工序加工
- 加工过程中的质量数据
- 是否有异常情况记录

### 8.4.3 批次管理

批次管理是质量追溯的基础，需要建立科学的批次号编码规则和批次追溯体系。

**批次号编码规则**：建议采用"产品代码+日期+流水号"格式，如：PRD-20240508-001。

**批次切割**：当生产批量过大或需要分批出货时，需要进行批次切割，将原批次拆分为多个子批次，每个子批次有独立的追溯信息。

### 8.4.4 追溯报告生成

追溯报告是质量追溯的输出，用于满足客户审核、监管要求、质量分析等需求。

**追溯查询**：支持按产品序列号、批次号、生产日期、客户订单等多种维度进行追溯查询。

**追溯报表**：自动生成追溯报告，包含完整的物料信息、生产信息、检验信息、时间轴等。

```sql
-- 追溯查询存储过程
CREATE PROCEDURE sp_trace_forward(IN p_lot_no VARCHAR(50))
BEGIN
    SELECT 
        lt.event_time,
        lt.event_type,
        lt.station_id,
        s.station_name,
        lt.operator_id,
        u.user_name as operator_name,
        lt.quantity_before,
        lt.quantity_change,
        lt.quantity_after,
        lt.remark
    FROM lot_trace lt
    LEFT JOIN station s ON lt.station_id = s.station_id
    LEFT JOIN user u ON lt.operator_id = u.user_id
    WHERE lt.lot_id = (SELECT lot_id FROM lot WHERE lot_no = p_lot_no)
    ORDER BY lt.event_time;
END;

-- 追溯报表生成
CREATE PROCEDURE sp_generate_trace_report(IN p_lot_no VARCHAR(50))
BEGIN
    SELECT 
        l.lot_no,
        p.product_code,
        p.product_name,
        l.quantity,
        l.production_date,
        (SELECT JSON_ARRAYAGG(
            JSON_OBJECT(
                'event_time', lt.event_time,
                'event_type', lt.event_type,
                'station', s.station_name,
                'operator', u.user_name,
                'quantity_change', lt.quantity_change
            )
        ) FROM lot_trace lt 
        LEFT JOIN station s ON lt.station_id = s.station_id 
        LEFT JOIN user u ON lt.operator_id = u.user_id
        WHERE lt.lot_id = l.lot_id) as trace_events
    FROM lot l
    JOIN product p ON l.product_id = p.product_id
    WHERE l.lot_no = p_lot_no;
END;
```

## 8.5 不良品处理

### 8.5.1 不良品判定

不良品判定需要依据明确的判定标准和流程，确保判定的准确性和一致性。

**判定标准**：根据产品技术标准、规格书、客户要求等制定不良品判定标准，明确各类缺陷的判定规则。不合格品分为：

- 严重不合格：安全项目不合格、关键特性超标
- 主要不合格：重要特性超标、功能受损
- 次要不合格：外观缺陷、非关键特性轻微超标

**判定流程**：

1. 检验人员发现不良品
2. 记录不良现象和数量
3. 依据判定标准进行判定
4. 标识和隔离不良品
5. 提交不良品处理申请

### 8.5.2 不良品流程

不良品根据判定结果选择不同的处理方式：

**返工（Rework）**：通过重新加工或返修使产品达到规定要求，不改变原设计。返工后需要重新检验。

**返修（Repair）**：通过维修使产品恢复使用功能，但可能影响产品性能或寿命。返修需要客户同意。

**降级（Downgrade）**：将产品降为次等级或用于其他用途，需要评估降级后的适用性。

**报废（Scrap）**：无法返工、返修或降级的不良品，进行报废处理。报废需要经过审批，并做好记录。


### 8.5.3 不良品分析

**帕累托分析（Pareto Analysis）**

帕累托分析基于"80/20法则"，找出影响质量的主要因素。多数质量问题往往由少数关键原因导致，通过帕累托图可以直观识别需要优先改进的问题。

```sql
-- 不良品帕累托分析
SELECT 
    defect_type,
    COUNT(*) as defect_count,
    SUM(defect_quantity) as total_quantity,
    ROUND(SUM(defect_quantity) * 100.0 / SUM(SUM(defect_quantity)) OVER(), 2) as cumulative_percentage
FROM defect_record
WHERE production_date BETWEEN '2024-01-01' AND '2024-12-31'
GROUP BY defect_type
ORDER BY total_quantity DESC;
```

**根本原因分析（Root Cause Analysis）**

常用的根本原因分析方法包括：

- **5 Why分析**：通过连续追问"为什么"找到问题根本原因
- **鱼骨图（Ishikawa图）**：从人、机、料、法、环、测六个方面分析原因
- **FMEA（失效模式与影响分析）**：识别潜在的失效模式及其影响

**案例：质量改善案例**

某汽车零部件厂发现某工序不良率偏高（5%），通过以下步骤进行改善：

1. **数据收集**：收集一个月的不良品数据，共200件不良
2. **帕累托分析**：发现焊接不良占比75%（150件），为首要问题
3. **原因分析**：焊接不良中，气孔占比80%，主要原因是焊丝受潮
4. **改善措施**：增加焊丝烘干工序、改善储存环境
5. **效果验证**：改善后不良率降至0.8%，达到目标值

```sql
-- 质量趋势分析
SELECT 
    DATE_FORMAT(production_date, '%Y-%m') as month,
    COUNT(*) as total_defects,
    SUM(defect_quantity) as total_quantity,
    ROUND(SUM(defect_quantity) * 100.0 / 
        (SELECT SUM(quantity) FROM work_order 
         WHERE DATE_FORMAT(completion_date, '%Y-%m') = DATE_FORMAT(production_date, '%Y-%m'))
    , 2) as defect_rate
FROM defect_record
GROUP BY DATE_FORMAT(production_date, '%Y-%m')
ORDER BY month;
```
