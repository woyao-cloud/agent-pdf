> 进阶实战型MES技术专著

## 书籍定位

**目标读者**：
- 制造企业生产管理人员/IT人员
- MES系统开发/实施工程师
- 制造业数字化转型咨询顾问

**内容定位**：进阶实战 - 深入原理、包含源码与案例、偏重实施与开发

## 书籍特色

- **算法+代码**：排程模块提供Python/伪代码实现
- **案例驱动**：每章含1-2个真实行业案例
- **问题导向**：以问题切入，引出解决方案
- **多视角**：同时覆盖管理、技术、咨询需求
