# 精通 PyTorch

> 一本面向开发者的 PyTorch 系统化深度指南：从底层原理到工程实践，从典型应用到性能优化与风险规避。

## 本书定位

本书不是又一本"PyTorch 入门教程"。它假设你已经接触过 Python 与基本的机器学习概念，希望真正**理解 PyTorch 的设计哲学、运行机制与工程边界**，并具备在生产环境中独立解决问题的能力。

阅读完本书，你应能够：

- 解释 PyTorch 在动态图、Autograd、Tensor 调度、CUDA 异步执行等关键机制的实现原理
- 准确判断 PyTorch 适用的业务场景与不适合的场景
- 识别并规避内存泄漏、数值不稳、训练发散、CUDA OOM、数据加载瓶颈等常见风险
- 系统性地优化训练与推理性能（混合精度、`torch.compile`、Flash Attention、分布式训练等）
- 排查并修复典型生产问题（NaN、梯度爆炸、显存碎片、推理抖动等）
- 掌握作为 PyTorch 开发者必备的核心技能与知识体系

## 版本说明

本书示例与机制描述基于 **PyTorch 2.x（2.3 / 2.4 / 2.5）** 主线版本，重点关注：

- `torch.compile`（PT 2.0 引入的图编译路径，TorchInductor）
- FSDP / FSDP2（完全分片数据并行）
- `torch.func`（函数式变换）
- Flash Attention v2、Scaled Dot-Product Attention 内核
- `torch.export`、`AOTInductor`（推理编译）

部分对比章节会回顾 1.x 时代 API（如 `torch.distributed.launch`、`apex.amp`），便于理解演化脉络。

## 写作风格约定

- 优先讲清楚**为什么这么设计**，而非只罗列 API
- 所有"建议"必须给出失败案例与权衡（trade-off）
- 代码块均为可运行的最小示例（minimal reproducible example）
- 数据规模、显存数字均标注**测试环境**（GPU 型号、PyTorch 版本）

> 如发现机制说明与你阅读的源码版本有差异，以源码为准 —— 本书欢迎以 issue 方式反馈勘误。
