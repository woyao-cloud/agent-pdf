# 第09章 计算机视觉典型场景

计算机视觉是 PyTorch 最早成熟的应用领域。从 ResNet 到 ViT、从 YOLO 到 Segment Anything，绝大多数 SOTA 模型都有 PyTorch 实现。本章不再重复"如何写 ResNet"，而是聚焦每类任务的**典型 pipeline、风险点、PyTorch 生态选型**。

---

## 9.1 视觉任务全景

| 任务 | 输入 → 输出 | 代表模型 | PyTorch 生态 |
|------|------------|---------|------------|
| 图像分类 | 图像 → 类别 | ResNet / EfficientNet / ViT / ConvNeXt | torchvision、timm |
| 目标检测 | 图像 → bbox + 类别 | Faster R-CNN / YOLO / DETR | torchvision、Ultralytics、mmdetection |
| 语义/实例分割 | 图像 → mask | DeepLab / Mask R-CNN / SAM | torchvision、mmsegmentation |
| 关键点检测 | 图像 → 点坐标 | HRNet / OpenPose | mmpose |
| 图像生成 | 噪声/文本 → 图像 | GAN / Diffusion / Stable Diffusion | diffusers |
| 视频理解 | 视频帧序列 → 类别/事件 | I3D / SlowFast / VideoMAE | torchvision、PyTorchVideo |
| 3D 视觉 | 点云/体素 → 类别/检测 | PointNet++ / 3DETR | PyTorch3D、open3d |
| 多模态 | 图像 + 文本 → 输出 | CLIP / BLIP / Flamingo | open_clip、LAVIS |

## 9.2 图像分类：最经典的入门 pipeline

### 9.2.1 模型来源

直接用 torchvision 或 timm 的预训练模型，几乎不需要从头实现：

```python
import torchvision.models as M
model = M.resnet50(weights=M.ResNet50_Weights.IMAGENET1K_V2)

# 或更全的 timm
import timm
model = timm.create_model('vit_base_patch16_224', pretrained=True)
```

`timm`（PyTorch Image Models）覆盖几乎所有 SOTA 视觉骨干，**视觉项目首选**。

### 9.2.2 微调要点

```python
# 1. 替换 head
model.fc = nn.Linear(model.fc.in_features, num_classes)
# 或对 ViT
model.head = nn.Linear(model.num_features, num_classes)

# 2. 决定是否冻结 backbone
for p in model.parameters():
    p.requires_grad = False
for p in model.fc.parameters():
    p.requires_grad = True

# 3. 不同学习率
optim = torch.optim.AdamW([
    {'params': model.fc.parameters(), 'lr': 1e-3},
    # 解冻 backbone 时再加：
    # {'params': [p for n, p in model.named_parameters() if 'fc' not in n], 'lr': 1e-5},
], weight_decay=0.05)
```

**经验**：

- 数据少（< 1k）→ 冻结 backbone，只训 head
- 数据中（1k-100k）→ 全量微调，backbone 用 1/100 主 lr
- 数据多（> 100k）或 domain shift 大 → 全量微调，统一 lr

### 9.2.3 数据增强

经典 ImageNet 训练增强：

```python
from torchvision.transforms import v2

train_tf = v2.Compose([
    v2.RandomResizedCrop(224, antialias=True),
    v2.RandomHorizontalFlip(),
    v2.RandAugment(num_ops=2, magnitude=9),
    v2.ToDtype(torch.float32, scale=True),
    v2.Normalize([0.485,0.456,0.406], [0.229,0.224,0.225]),
    v2.RandomErasing(p=0.25),
])
```

进阶：MixUp、CutMix（在 batch 级别混合）：

```python
from torchvision.transforms import v2
mixup = v2.MixUp(num_classes=num_classes)
cutmix = v2.CutMix(num_classes=num_classes)
mixer = v2.RandomChoice([mixup, cutmix])

# 在 collate_fn 之后应用
imgs, labels = mixer(imgs, labels)   # labels 变成 one-hot soft label
loss = soft_target_cross_entropy(out, labels)
```

### 9.2.4 风险点

- **预训练 mean/std 不匹配**：用 ImageNet 预训练模型却没归一化 → 准确率显著下降
- **resolution 不匹配**：ViT 预训练在 224×224，直接用 384×384 推理需要插值位置编码
- **类别极不平衡**：用 WeightedRandomSampler 或 Focal Loss

## 9.3 目标检测

### 9.3.1 主流方案

| 模型族 | 特点 | 推荐场景 |
|------|------|---------|
| YOLO（v5/v8/v11） | 单阶段，速度最快 | 实时、边缘 |
| Faster R-CNN | 双阶段，精度高 | 学术、小目标 |
| DETR / DINO | 端到端，无 NMS | 大数据，简洁 |
| Cascade R-CNN | 多阶段精修 | 高精度需求 |

工业项目：YOLO（Ultralytics）几乎是 90% 场景的默认选择。学术研究：mmdetection。

### 9.3.2 数据格式与 collate_fn

检测样本是 **(image, list of boxes)** —— boxes 数量每张图不同：

```python
def collate_det(batch):
    imgs = torch.stack([b['image'] for b in batch])
    targets = [{'boxes': b['boxes'], 'labels': b['labels']} for b in batch]
    return imgs, targets
```

模型 forward 接受 list 形式 target（torchvision detection API 的约定）。

### 9.3.3 损失与后处理

检测损失通常是分类 + 回归的组合（class loss + box loss），并配合 NMS 后处理。Anchor-based 模型还要 anchor 匹配。

**陷阱**：

- 训练时 `model(imgs, targets)` 返回 loss dict，推理时 `model(imgs)` 返回检测结果 —— API 模式不同，切换时要小心
- IoU、coord 计算要避免负宽高 / NaN，用 `torch.clamp(min=eps)`
- 验证时 NMS 阈值 / score 阈值与训练分离设定

### 9.3.4 评估指标

mAP（mean Average Precision）需要专门库计算（COCO API、torchmetrics）：

```python
from torchmetrics.detection import MeanAveragePrecision
metric = MeanAveragePrecision(iou_type='bbox')
metric.update(preds, targets)
print(metric.compute())   # 返回 dict 含 map_50, map_75, map_small...
```

## 9.4 语义分割

### 9.4.1 输入输出与损失

输入图像 (B, 3, H, W)，输出分割图 (B, num_classes, H, W)，逐像素 CrossEntropy：

```python
out = model(imgs)                    # (B, C, H, W) logits
loss = F.cross_entropy(out, masks, ignore_index=255)
```

`ignore_index=255` 是 Cityscapes 等数据集的"忽略"约定。

### 9.4.2 常用结构

| 模型 | 特点 |
|------|------|
| U-Net | 医学影像、对称 encoder-decoder |
| DeepLab v3+ | 空洞卷积，建筑/城市 |
| SegFormer | 轻量 Transformer |
| Mask2Former | 通用分割（语义+实例+全景） |
| **SAM / SAM2** | 零样本通用分割（提示驱动） |

### 9.4.3 数据增强对分割的特殊性

mask 必须与 image **同步增强**（同样的 crop / flip）。`torchvision.transforms.v2` 原生支持：

```python
tf = v2.Compose([
    v2.RandomResizedCrop(512, antialias=True),
    v2.RandomHorizontalFlip(),
    v2.ToDtype(torch.float32, scale=True),
])
img, mask = tf(img, mask)    # v2 自动同步几何变换
```

颜色空间增强（亮度/对比度）只对 image，不对 mask。v2 也会处理。

### 9.4.4 评估指标

- mIoU（mean Intersection over Union）：分类无关的核心指标
- pixel accuracy：易被大类支配，慎用单独看
- Dice：医学影像常用

```python
from torchmetrics import JaccardIndex   # = IoU
miou = JaccardIndex(task='multiclass', num_classes=21, average='macro')
```

## 9.6 视频理解

视频 = 时间维度的图像序列。常用张量布局：

```
(B, C, T, H, W)   # 时空 conv 模型，如 I3D、SlowFast
(B, T, C, H, W)   # 帧级 transformer，如 VideoMAE
```

### 9.6.1 PyTorchVideo

```python
import pytorchvideo.models.x3d as x3d
model = x3d.create_x3d(model_name='x3d_m', pretrained=True)
```

### 9.6.2 视频 I/O 瓶颈

视频解码（解码 H.264 / H.265）极费 CPU。优化路径：

| 方法 | 加速 |
|------|------|
| `decord` 库（替代 PyAV/OpenCV） | 2-5x |
| NVIDIA DALI 视频解码 | GPU 解码，5-10x |
| 预提取帧到 LMDB / TAR | 无需解码，最快 |

### 9.6.3 时间采样

整段视频不能完整放入 GPU，需要采样固定帧数：

```python
# 均匀采样 16 帧
indices = np.linspace(0, total_frames - 1, 16).astype(int)
clip = video[indices]
```

或随机采样（训练）+ 均匀采样（验证），TSN（temporal segment networks）的标准策略。

## 9.7 图像生成：Diffusion 主导

### 9.7.1 库选择

| 库 | 用途 |
|------|------|
| **diffusers**（HuggingFace） | 主流 diffusion 训练/推理框架 |
| ldm（CompVis） | Stable Diffusion 原始实现 |
| ComfyUI / WebUI | 推理 / 工作流编排 |

### 9.7.2 简化的训练循环（DDPM）

```python
for x_0, _ in loader:
    t = torch.randint(0, T, (x_0.size(0),), device=device)
    noise = torch.randn_like(x_0)
    x_t = sqrt_alpha_cumprod[t][:, None, None, None] * x_0 + \
          sqrt_one_minus_alpha_cumprod[t][:, None, None, None] * noise
    pred = unet(x_t, t)
    loss = F.mse_loss(pred, noise)
    loss.backward()
    optimizer.step()
```

### 9.7.3 推理时关键技巧

- **classifier-free guidance**：训练时 10% 概率丢弃条件，推理时 `pred = pred_uncond + s * (pred_cond - pred_uncond)`
- **采样器**：DDPM 1000 步 → DDIM 50 步 → DPM-Solver 20 步，速度差异巨大
- **EMA 权重**：训练时维护权重指数滑动平均，推理用 EMA 版本

### 9.7.4 Stable Diffusion 微调

LoRA、Dreambooth、Textual Inversion 等技术让消费级 GPU 也能微调 SD：

```python
from peft import LoraConfig, get_peft_model
config = LoraConfig(r=8, target_modules=['to_q', 'to_v'])
unet = get_peft_model(unet, config)
# 只训 LoRA 权重
```

## 9.8 多模态：CLIP 系

CLIP（Contrastive Language-Image Pretraining）让图像和文本进入共享空间：

```python
import open_clip
model, _, preprocess = open_clip.create_model_and_transforms('ViT-B-32', pretrained='laion2b_s34b_b79k')

img_features = model.encode_image(preprocess(img).unsqueeze(0))
text_features = model.encode_text(open_clip.tokenize(['a cat', 'a dog']))
img_features /= img_features.norm(dim=-1, keepdim=True)
text_features /= text_features.norm(dim=-1, keepdim=True)
similarity = img_features @ text_features.T
```

应用：

- 零样本分类
- 图文检索
- 作为大模型的视觉编码器（LLaVA 等）

## 9.9 视觉常见性能与正确性陷阱

| 陷阱 | 典型现象 | 处理 |
|------|---------|------|
| BN running stats 在 fine-tune 时被破坏 | 验证集严重退化 | 冻结 BN 或用 SyncBN |
| 输入未归一化 | 训练 loss 不下降 | 检查 mean / std |
| RGB ↔ BGR 颠倒 | 准确率离奇低 | OpenCV 默认 BGR，需要 `cv2.cvtColor` |
| ToTensor 与 ToDtype 混用 | dtype/scale 错乱 | 用 v2 系列 |
| label smoothing 与 sigmoid 多标签混用 | loss NaN | 二分类 / 多标签用 BCE |
| crop 后 box 出界 | 训练发散 | 用 `clip` + 过滤 |
| 大模型在小卡上 OOM | CUDA OOM | 减 batch、混精、checkpoint、FSDP（详见 13、15 章） |
| dataloader 慢 | GPU 利用率低 | num_workers / pin_memory / 缓存解码 |

## 9.11 本章小结

- 视觉模型几乎不需要从头实现，用 torchvision/timm/diffusers/open_clip
- 微调三档：冻结/部分/全量，对应数据规模和 domain shift
- 检测 / 分割 / 视频 / 生成各有标准 pipeline，差别在数据格式和损失结构
- 多模态（CLIP）已成视觉系统的标准组件
- 视觉性能瓶颈常在数据 pipeline（解码、增强）而非模型本身
- 工程化：用 timm + Lightning + WandB + Hydra 是 2024 年的主流栈
