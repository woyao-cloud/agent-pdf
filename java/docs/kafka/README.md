# 精通Kafka（Java版）

> 场景·原理·实战·优化

## 书籍定位

本书面向Java开发工程师、大数据工程师和架构师，**以场景驱动**的方式系统讲解Kafka的核心应用场景、实现原理、潜在风险和优化策略。每一个场景都配有完整的Docker Compose环境和Java示例代码，可本地运行验证。

## 场景速查

| 场景 | 适用场景 | 核心价值 |
|------|---------|---------|
| 异步消息解耦 | 服务间异步通信 | 削峰填谷、服务解耦 |
| 事件驱动架构 | 微服务事件通知 | 最终一致性、事件溯源 |
| 日志收集 | 集中式日志管理 | 统一收集、实时索引 |
| 流式处理 | 实时计算 | 秒级延迟处理 |
| 数据管道ETL | 异构数据同步 | 批量迁移、实时同步 |
| 变更数据捕获CDC | 数据库变更同步 | 增量同步、零侵入 |
| 指标监控 | 系统监控告警 | 实时监控、聚合分析 |
| 事务消息 | 分布式事务 | 精确一次语义 |
| 消息广播 | 配置下发、状态同步 | 一对多分发 |
| 死信队列重试 | 异常消息处理 | 故障隔离、自动恢复 |

## 环境要求

- JDK 11+
- Docker & Docker Compose
- Apache Kafka 3.x
- Maven / Gradle

## Docker Compose

每个场景的Docker Compose配置位于 `docker/` 目录下，可直接启动运行：

```bash
cd docker/scenario-04-async
docker-compose up -d
```
