# 第5章 双级检索机制

## 5.1 低层检索（Low-Level）

### 解决的问题

对于需要精确事实的查询（如"iPhone 15 用什么芯片？"），需要基于实体和关系的精确匹配，而不是模糊的向量相似度。

### 核心原理

低层检索基于图结构中的实体和关系进行精确匹配。当用户查询包含特定实体时，LightRAG 直接在图中查找该实体的属性和关系，返回最相关的事实。

### 代码/配置实现

```python
from lightrag import LightRAG
from lightrag.llm import gpt_4o_mini_complete

rag = LightRAG(working_dir="./lightrag_cache", llm_func=gpt_4o_mini_complete)

rag.insert("iPhone 15 搭载了 A17 Pro 芯片，起售价 799 美元。")

# 低层检索 - 精确事实
answer = rag.query("iPhone 15 用什么芯片？", mode="low")
print(answer)  # A17 Pro 芯片
```

### 使用场景

- 事实性问答
- 实体属性查询
- 关系查询

### 潜在风险与注意事项

- 依赖实体提取的准确性
- 同义词实体可能无法匹配

### 本章小结

- 低层检索基于实体和关系精确匹配
- 适合具体事实查询
- 检索结果精确但范围有限

---

## 5.2 高层检索（High-Level）

### 解决的问题

对于需要全局理解的查询（如"苹果公司的发展历程"），需要综合多个文档的信息，而不是单个事实。

### 核心原理

高层检索基于图结构的全局摘要。LightRAG 通过分析图结构中的实体分布和关系密度，生成对文档集的全局理解。

### 代码/配置实现

```python
# 高层检索 - 全局概览
answer = rag.query("苹果公司的发展历程", mode="high")
print(answer)  # 包含公司成立、产品发布等综合信息
```

### 使用场景

- 主题概览
- 文档集摘要
- 趋势分析

### 潜在风险与注意事项

- 高层检索可能丢失细节
- 依赖图结构的完整性

### 本章小结

- 高层检索基于图结构全局摘要
- 适合主题和概览查询
- 检索结果全面但可能不够精确

---

## 5.3 混合检索策略

### 解决的问题

结合低层和高层检索的优势，同时提供精确事实和全局理解。

### 核心原理

混合检索同时执行低层和高层检索，将结果融合后输入 LLM 生成最终回答。

### 代码/配置实现

```python
# 混合检索 - 综合
answer = rag.query("苹果公司的创始人和最新产品", mode="hybrid")
print(answer)  # 同时包含创始人和产品信息
```

### 使用场景

- 复杂问题回答
- 综合分析
- 多维度查询

### 潜在风险与注意事项

- 混合检索 Token 消耗更高
- 结果融合可能引入冗余

### 本章小结

- 混合检索结合低层和高层优势
- 适合复杂查询
- Token 消耗介于两者之间
