# LightRAG 原理与实践：轻量级图增强检索生成

> 从图索引到 Graph RAG 的完整指南

## 书籍定位

本书面向 AI 工程师、RAG 开发者、NLP 研究员和知识图谱工程师，系统讲解 LightRAG 的原理、实践与架构设计。内容覆盖从 RAG 基础到 LightRAG 双级检索机制的全栈知识体系。
