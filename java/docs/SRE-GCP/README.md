# GCP SRE 实战操作手册

![SRE on Google Cloud]

## 关于本书

这是一本面向 **GCP (Google Cloud Platform) SRE 工程师** 的实战操作手册（Playbook/Runbook）。它兼顾了 **SRE 核心理论** 与 **GCP 平台的深度实操**，目标是帮助希望将 SRE 最佳实践落地到 GCP 环境中的工程师，能够真正"上手干活"。

本书不仅讲解"是什么"，更强调"怎么做"——尤其是在凌晨三点 On-call 时，你能快速翻阅找到解决方案。

## 目标读者

- 正在或即将在 GCP 上承担 SRE/运维职责的工程师
- 希望将 SRE 方法论落地到云原生环境中的 DevOps 工程师
- 从传统运维转型到云上 SRE 的技术人员
- 备考 Google Professional Cloud DevOps Engineer 认证的考生

## 如何使用本书

本书按七个部分组织，共 32 章 + 2 个附录，建议按顺序阅读，但也可以作为参考手册按需翻阅：

| 部分 | 章节 | 主题 | 适合场景 |
|------|------|------|---------|
| 第一部分 | ch01-ch04 | SRE 基石与文化 | 建立 SRE 理论基础 |
| 第二部分 | ch05-ch11 | GCP 核心架构与高可用设计 | 理解 GCP 平台底座 |
| 第三部分 | ch12-ch16 | 可观测性体系构建 | 日常监控排障必读 |
| 第四部分 | ch17-ch19 | IaC 与自动化 | 基础设施自动化建设 |
| 第五部分 | ch20-ch22 | 容量规划与 FinOps | 成本与性能优化 |
| 第六部分 | ch23-ch28 | 事件响应与故障排查 | On-call 实战手册 |
| 第七部分 | ch29-ch32 | 安全与合规 | 安全基线建设 |
| 附录 | appendix-* | 工具箱与速查表 | 快速查阅 |

## 核心理念

本书遵循几条贯穿始终的原则：

1. **场景驱动**：每个技能都放在一个真实的故障或场景中讲解
2. **反模式同样重要**：明确指出在 GCP 上"不该做什么"
3. **标签文化是基础**：没有良好的标签策略，监控、计费和自动化都将混乱
4. **可操作性第一**：所有内容都以"你能拿起来就用"为目标
