## 写作建议

1. **场景驱动**：不要只罗列产品功能，而是写"当 TKE Pod 处于 CrashLoopBackOff 时，SRE 应如何在 5 分钟内定位问题"
2. **真实代码**：包含大量 Terraform 代码块、tccli 命令、Python 脚本，读者可直接复制使用
3. **反模式**：明确指出"不要在代码中硬编码 SecretId/SecretKey"、"不要为所有资源赋予 QcloudCAMFullAccess"
4. **决策树**：多画故障排查决策树和事件响应流程图
5. **标签文化**：强调标签 (Tag) 规范对监控、计费和自动化的重要性

**使用步骤：**
1. 安装腾讯云 CLI：`pip install tccli` 并配置密钥
2. 安装 Terraform：`choco install terraform` 并配置腾讯云 Provider
3. Terraform 脚本：进入对应目录执行 `terraform init && terraform plan && terraform apply`
4. Python 脚本：`pip install tencentcloud-sdk-python` 后直接运行
5. Shell 脚本：需配置 `SECRET_ID` 和 `SECRET_KEY` 环境变量
6. YAML 配置：通过 `kubectl apply -f` 或 TKE 控制台导入
