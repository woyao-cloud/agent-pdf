# 第6章 如何选择——6 个典型决策场景

## 6.1 场景一：你是在校研究生/科研人员

**建议：PyTorch。**

如果你需要发表论文、复现他人的研究、或者探索新的模型结构，PyTorch 是目前最自然的选择。原因有三：

第一，90% 的论文代码用 PyTorch 实现。如果你想复现一篇 CVPR 或 NeurIPS 论文，大概率能找到 PyTorch 实现。你不需要把代码从一种框架"翻译"到另一种。

第二，PyTorch 的灵活性和调试体验让你可以快速尝试新想法。研究本质上是一个"大量试错"的过程。PyTorch 的快速迭代能力在这个循环中非常重要。

第三，学术社区的资源几乎都围绕 PyTorch。从预训练模型到教程到讨论区，PyTorch 的资源远多于 TensorFlow。

## 6.2 场景二：你在创业公司做 MVP

**建议：PyTorch。**

创业公司的核心需求是"快速验证"。PyTorch 的快速迭代适合这种模式。另外，招聘也是一个考量——目前会用 PyTorch 的人远多于会用 TensorFlow 的人。

一个常见的混合策略是：PyTorch 训练 + ONNX 转换 + TF Serving 部署。这结合了 PyTorch 的开发效率和 TF Serving 的部署成熟度。

## 6.3 场景三：你在大型企业做生产部署

**建议：看现状。**

如果有大量 TensorFlow 存量代码，继续使用是合理的选择。如果是新项目，建议 PyTorch——趋势向上，招人更容易。

## 6.4 场景四：你要做移动端 AI

**建议：TensorFlow（TFLite 更成熟）。**

TFLite 在 Android 上的优化力度大，支持 GPU 加速、NPU 加速、模型量化。PyTorch Mobile 在追赶，但目前 TFLite 更稳妥。

## 6.5 场景五：你想找深度学习的工作

**建议：主学 PyTorch。**

大部分深度学习岗位要求 PyTorch。有余力可以了解 TensorFlow 的 Keras API 和 TF Serving。

## 6.6 场景六：你是企业技术选型决策者

**建议：优先 PyTorch（趋势向上），评估部署需求。**

注意一个例外：移动端推理选 TensorFlow。在线推理两种框架都行，基于团队技术栈决定。

## 决策速查表

| 你的身份 | 推荐框架 | 理由 |
|---------|---------|------|
| 研究生/科研人员 | PyTorch | 论文生态、快速实验 |
| 创业公司 | PyTorch | 快速迭代、招聘 |
| 大型企业（有存量） | 维持现有 | 切换成本太高 |
| 大型企业（新项目） | PyTorch | 趋势向上 |
| 移动端 AI | TensorFlow | TFLite 成熟 |
| 求职者 | PyTorch 为主 | 市场需求更大 |
| 技术决策者 | 优先 PyTorch | 长期趋势 |
