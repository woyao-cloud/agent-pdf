# 附录 A：Grafana 快捷键与 UI 操作效率指南

## 全局快捷键

| 快捷键 | 操作 | 说明 |
|--------|------|------|
| `Ctrl+S` | 保存 Dashboard | 保存当前修改 |
| `Ctrl+Shift+S` | 另存为 | 保存为新 Dashboard |
| `Ctrl+Z` | 撤销 | 撤销上一步操作 |
| `Ctrl+Shift+Z` | 重做 | 重做上一步撤销 |
| `Escape` | 关闭面板编辑 | 退出当前面板编辑模式 |
| `F` | 全屏切换 | 切换当前面板的全屏模式 |
| `R` | 刷新 Dashboard | 重新加载所有面板数据 |

## 面板编辑快捷键

| 快捷键 | 操作 | 说明 |
|--------|------|------|
| `Ctrl+Enter` | 执行查询 | 在 Explore 中执行查询 |
| `Shift+Enter` | 新行 | 在查询编辑器中添加新行 |
| `Alt+↑/↓` | 移动面板 | 在 Dashboard 中上下移动面板 |
| `Ctrl+C/V` | 复制/粘贴面板 | 在不同 Dashboard 间复制面板 |

## 时间范围快捷键

| 快捷键 | 操作 |
|--------|------|
| `t` + `←` | 时间范围向前 |
| `t` + `→` | 时间范围向后 |
| `t` + `z` | 缩放到选中的时间范围 |
| `t` + `o` | 切换到上一时间范围 |

## 鼠标操作

| 操作 | 效果 |
|------|------|
| 在图表上拖拽 | 选中时间范围 |
| 按住 `Ctrl` + 滚轮 | 缩放时间范围 |
| 双击图表 | 重置时间范围 |
| 悬停数据点 | 查看数据详情 |
| 点击图例 | 隐藏/显示序列 |

## Explore 模式快捷键

| 快捷键 | 操作 |
|--------|------|
| `Ctrl+/` | 切换快捷键帮助 |
| `Ctrl+Enter` | 执行查询 |
| `Ctrl+Shift+Enter` | 执行查询（新标签页）|
| `Tab` | 自动补全查询 |
| `↑/↓` | 历史查询导航 |
