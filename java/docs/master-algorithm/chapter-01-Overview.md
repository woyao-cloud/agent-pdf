# 第1章 算法概述

## 1.1 什么是算法

**算法（Algorithm）** 是解决特定问题的有限步骤序列，是一种精确的、明确的、可执行的计算过程。算法接收输入，经过一系列有限的操作后产生输出。

### 算法的定义

从不同角度理解算法：

| 角度 | 定义 |
|------|------|
| 数学角度 | 有穷性、确定性、可行性、输入、输出 |
| 计算机角度 | 对数据结构的加工过程 |
| 工程角度 | 用时间换空间或用空间换时间的权衡 |

### 算法的核心特征

```java
// 算法的五个特征
public class AlgorithmFeatures {
    // 1. 输入：有零个或多个输入
    int sum(int[] arr) {  // 输入：数组
        int total = 0;
        for (int i = 0; i < arr.length; i++) {
            total += arr[i];
        }
        return total;  // 输出：总和
    }

    // 2. 输出：至少有一个输出
    // 3. 确定性：每条指令含义明确
    // 4. 有穷性：有限步结束
    // 5. 可行性：基本操作可执行
}
```

## 1.2 算法的特征与评价标准

### 算法的五大特征

| 特征 | 说明 | 示例 |
|------|------|------|
| **输入** | 零个或多个输入 | 排序算法的数组 |
| **输出** | 至少一个输出 | 排序结果 |
| **确定性** | 每步操作明确无歧义 | arr[i] vs arr[i+1] |
| **有穷性** | 有限步骤内完成 | for循环 vs 死循环 |
| **可行性** | 基本操作可执行 | 简单原子操作 |

### 算法的评价标准

#### 正确性（Correctness）

算法必须能够正确地解决问题：

```java
// 正确的二分查找
public int binarySearch(int[] arr, int target) {
    int left = 0, right = arr.length - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (arr[mid] == target) return mid;
        else if (arr[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}
```

#### 时间复杂度（Time Complexity）

算法执行时间随输入规模的增长趋势：

| 级别 | 名称 | 增长率 | 示例 |
|------|------|--------|------|
| O(1) | 常数时间 | 1 | 数组访问 |
| O(log n) | 对数时间 | log n | 二分查找 |
| O(n) | 线性时间 | n | 遍历 |
| O(n log n) | 线性对数时间 | n log n | 归并排序 |
| O(n²) | 平方时间 | n² | 冒泡排序 |
| O(2ⁿ) | 指数时间 | 2^n | 递归斐波那契 |

#### 空间复杂度（Space Complexity）

算法所需的内存空间：

```java
// O(1)空间
public int sum(int[] arr) {
    int sum = 0;  // 常数个变量
    for (int i = 0; i < arr.length; i++) sum += arr[i];
    return sum;
}

// O(n)空间
public int[] copy(int[] arr) {
    int[] copy = new int[arr.length];  // 新数组
    for (int i = 0; i < arr.length; i++) copy[i] = arr[i];
    return copy;
}
```

#### 可读性与可维护性

```java
// 好的算法代码
public int findMax(int[] arr) {
    if (arr == null || arr.length == 0) {
        throw new IllegalArgumentException("数组不能为空");
    }
    int max = arr[0];
    for (int i = 1; i < arr.length; i++) {
        if (arr[i] > max) max = arr[i];
    }
    return max;
}
```

### 算法选择原则

```
选择算法时需要考虑：
```

### 算法与数据结构的区别

| 维度 | 算法 | 数据结构 |
|------|------|----------|
| 定义 | 解决问题的方法步骤 | 数据的组织方式 |
| 核心 | "怎么做" | "怎么存" |

| 例子 | 排序算法 | 数组、链表 |

> 程序 = 数据结构 + 算法 —— Niklaus Wirth

### 从算法到程序

```java
// 问题：找出数组中的最大值
// 算法：线性扫描比较

// Step 1: 设计算法
// 1. 假设第一个元素为最大值
// 2. 依次与后面的元素比较
// 3. 如果发现更大的，更新最大值
// 4. 遍历完成后的最大值即为结果

// Step 2: 编码实现
public int findMax(int[] arr) {
    int max = arr[0];
    for (int i = 1; i < arr.length; i++) {
        if (arr[i] > max) {
            max = arr[i];
        }
    }
    return max;
}

// Step 3: 复杂度分析
// 时间复杂度: O(n)
// 空间复杂度: O(1)
```

### 案例：设计求两个数组交集的算法

```java
// Step 1: 理解问题
// 输入: 两个整数数组
// 输出: 两个数组的交集（去重）
// 约束: 时间效率优先

// Step 2: 分析问题
// 数组大小: 假设为m和n

// Step 3: 设计算法
// 方案A: 暴力法 - O(m*n)
// 方案B: 排序 + 双指针 - O(m log m + n log n)
// 方案C: 哈希表 - O(m+n), 空间O(m)

// Step 4: 选择最优方案（哈希表）
public int[] intersection(int[] nums1, int[] nums2) {
    // 使用HashSet去重
    Set<Integer> set1 = new HashSet<>();
    for (int num : nums1) set1.add(num);

    Set<Integer> result = new HashSet<>();
    for (int num : nums2) {
        if (set1.contains(num)) {
            result.add(num);
        }
    }

    return result.stream().mapToInt(Integer::intValue).toArray();
}

// Step 5: 复杂度分析
// 时间: O(m+n)
// 空间: O(m)
```

### 常见算法设计策略

| 策略 | 核心思想 | 适用问题 |
|------|----------|----------|
| **分治** | 分解→解决→合并 | 归并排序、快速排序 |
| **贪心** | 局部最优→全局最优 | 活动选择、Huffman |
| **动态规划** | 记忆化搜索最优子结构 | 背包、最长公共子序列 |
| **回溯** | 尝试→回退→剪枝 | 全排列、N皇后 |
| **分支限界** | 广度优先 + 剪枝 | 最短路径 |
| **枚举** | 遍历所有可能 | 暴力搜索 |
