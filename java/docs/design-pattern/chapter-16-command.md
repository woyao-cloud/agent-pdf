# 第16章 命令模式（Command）
+**命令模式**将请求封装为对象，从而使不同的请求参数化、队列化，或记录日志，以及支持可撤销操作。
+## 16.1 解决的问题与应用场景
+### 16.1.1 问题分析
+在软件系统中，经常需要将操作封装为对象：```java
+// 假设有一个编辑器，支持：// 1. 复制// 2. 粘贴// 3. 撤销// 4. 重做+// 问题：+// - 操作和执行混在一起// - 难以实现撤销/重做// - 难以记录操作日志// - 难以将操作加入队列```++### 16.1.2 典型应用场景++**1. 撤销/重做**```java+// 每个操作都是命令，可以保存/恢复Command command = new DeleteCommand(text, start, end);command.execute();undoManager.undo();  // 撤销undoManager.redo();  // 重做```++**2. 任务队列**```java
+// 将命令放入队列，异步执行Command cmd = new AsyncTaskCommand(task);queue.enqueue(cmd);  // 加入队列```++**3. 日志记录**```java+// 记录所有操作，用于审计Command cmd = new UpdateCommand(user, data);logger.log(cmd);  // 记录日志cmd.execute();```++**4. 宏命令**```java+// 组合多个命令为一个大命令Command macro = new MacroCommand(Arrays.asList(cmd1, cmd2, cmd3));macro.execute();  // 执行所有```+## 16.2 实现原理与UML
+### 16.2.1 核心思想
+命令模式的核心是**将操作封装为命令对象**，命令对象包含执行操作所需的所有信息，客户端只需要调用命令的execute()方法即可。+### 16.2.2 UML类图+```┌─────────────────────┐        ┌─────────────────────┐│   Invoker           │        │     Command        ││   (调用者)          │        │    (抽象命令)       │├─────────────────────┤        ├─────────────────────┤│ - command           │───────►│ + execute()        ││ + setCommand()      │        │ + undo()           ││ + invoke()          │        └──────────┬──────────┘│                     │                 │    ┌────────────┴────────────┐│                     │                 │                         │    ▼                         ▼            ┌─────────────────┐   ┌─────────────────┐│   Client        │   │ ConcreteCommand││   (客户端)      │   │  (具体命令)     │├─────────────────┤   ├─────────────────┤│ - command       │   │ - receiver      ││ - receiver      │   │ - state         │└─────────────────┘   │ + execute()     │                         │ + undo()        │                         └─────────────────┘                                    │                                    ▼                             ┌─────────────────┐                             │    Receiver    │                             │   (接收者)     │                             ├─────────────────┤                             │ + action()     │                             └─────────────────┘```+++### 16.2.3 角色分析+- **Command（抽象命令）**：定义命令的接口，声明执行的方法- **ConcreteCommand（具体命令）**：将接收者对象绑定于命令，调用接收者的操作- **Invoker（调用者）**：请求命令执行- **Receiver（接收者）**：真正执行操作的对象- **Client（客户端）**：创建具体命令对象并设置其接收者+### 16.2.4 时序图+```Client         Invoker        ConcreteCommand      Receiver   │              │               │                │   │              │               │                │   │ create       │               │                │   │ ───────────►│               │                │   │              │               │                │   │ setCommand() │               │                │   │ ───────────►│               │                │   │              │               │                │   │ invoke()     │               │                │   │ ───────────►│               │                │   │              │               │                │   │              │ execute()     │                │   │              │ ─────────────►│                │   │              │               │                │   │              │               │   action()    │   │              │               │ ─────────────►│   │              │               │                │   │              │               │    result      │   │              │ ◄─────────────│◄──────────────│   │              │               │                │   │```+## 16.3 代码实现
+### 16.3.1 基础实现++**抽象命令**```java
+public interface Command {    void execute();    void undo();}```+**接收者**```java
+// 文本编辑器+public class TextEditor {    private StringBuilder content = new StringBuilder();        public void insert(int position, String text) {        content.insert(position, text);    }        public void delete(int start, int end) {        content.delete(start, end);    }        public String getContent() {        return content.toString();    }        public void setContent(String content) {        this.content = new StringBuilder(content);    }}```+**具体命令 - 插入命令**```java
+public class InsertCommand implements Command {    private TextEditor editor;    private int position;    private String text;        public InsertCommand(TextEditor editor, int position, String text) {        this.editor = editor;        this.position = position;        this.text = text;    }        @Override    public void execute() {        editor.insert(position, text);    }        @Override    public void undo() {        editor.delete(position, position + text.length());    }}```+**具体命令 - 删除命令**```java
+public class DeleteCommand implements Command {    private TextEditor editor;    private int start;    private int end;    private String deletedText;        public DeleteCommand(TextEditor editor, int start, int end) {        this.editor = editor;        this.start = start;        this.end = end;    }        @Override    public void execute() {        deletedText = editor.getContent().substring(start, end);        editor.delete(start, end);    }        @Override    public void undo() {        editor.insert(start, deletedText);    }}```+**调用者 - 命令管理器**```java
+public class CommandManager {    private Stack<Command> undoStack = new Stack<>();    private Stack<Command> redoStack = new Stack<>();        public void executeCommand(Command command) {        command.execute();        undoStack.push(command);        redoStack.clear();  // 新命令后清空重做栈    }        public void undo() {        if (!undoStack.isEmpty()) {            Command command = undoStack.pop();            command.undo();            redoStack.push(command);        }    }        public void redo() {        if (!redoStack.isEmpty()) {            Command command = redoStack.pop();            command.execute();            undoStack.push(command);        }    }        public boolean canUndo() {        return !undoStack.isEmpty();    }        public boolean canRedo() {        return !redoStack.isEmpty();    }}```+**使用**```java
+public class Main {    public static void main(String[] args) {        TextEditor editor = new TextEditor();        CommandManager manager = new CommandManager();                // 输入文本        manager.executeCommand(new InsertCommand(editor, 0, "Hello "));        System.ou t. println(editor.getContent());  // Hello                manager.executeCommand(new InsertCommand(editor, 6, "World"));        System.ou t. println(editor.getContent());  // Hello World                // 撤销        manager.undo();        System.ou t. println(editor.getContent());  // Hello                // 重做        manager.redo();        System.ou t. println(editor.getContent());  // Hello World    }}```++### 16.3.2 宏命令++```java
+// 宏命令 - 一次执行多个命令public class MacroCommand implements Command {    private List<Command> commands;        public MacroCommand(List<Command> commands) {        this.commands = commands;    }        @Override    public void execute() {        for (Command command : commands) {            command.execute();        }    }        @Override    public void undo() {        // 反向撤销        for (int i = commands.size() - 1; i >= 0; i--) {            commands.get(i).undo();        }    }}++// 使用：复制粘贴多个文本public class Main {    public static void main(String[] args) {        TextEditor editor = new TextEditor();        CommandManager manager = new CommandManager();                List<Command> commands = Arrays.asList(            new InsertCommand(editor, 0, "Hello "),            new InsertCommand(editor, 6, "World"),            new InsertCommand(editor, 11, "!"));                MacroCommand macro = new MacroCommand(commands);        manager.executeCommand(macro);        System.ou t. println(editor.getContent());  // Hello World!                manager.undo();        System.ou t. println(editor.getContent());  // (空)    }}```++### 16.3.3 异步任务队列++```java
+// 命令队列public class CommandQueue {    private BlockingQueue<Command> queue = new LinkedBlockingQueue<>();    private ExecutorService executor = Executors.newSingleThreadExecutor();        public void enqueue(Command command) {        queue.offer(command);    }        public void start() {        executor.execute(() -> {            while (!Thread.currentThread().isInterrupted()) {                try {                    Command command = queue.take();                    command.execute();                } catch (InterruptedException e) {                    break;                }            }        });    }        public void stop() {        executor.shutdown();    }}++// 使用：后台任务队列public class Main {    public static void main(String[] args) {        CommandQueue queue = new CommandQueue();        queue.start();                queue.enqueue(() -> System.ou t. println("任务1执行"));        queue.enqueue(() -> System.ou t. println("任务2执行"));        queue.enqueue(() -> System.ou t. println("任务3执行"));    }}```+## 16.4 JDK/框架源码解析

+### 16.5.1 遥控器++```java
+// 命令接口public interface Command {    void execute();    void undo();}++// 接收者 - 电器public class Light {    public void on() { System.out.println("灯开了"); }    public void off() { System.out.println("灯关了"); }}++// 具体命令 - 开灯public class LightOnCommand implements Command {    private Light light;        public LightOnCommand(Light light) {        this.light = light;    }        @Override    public void execute() { light.on(); }        @Override    public void undo() { light.off(); }}++// 具体命令 - 关灯public class LightOffCommand implements Command {    private Light light;        public LightOffCommand(Light light) {        this.light = light;    }        @Override    public void execute() { light.off(); }        @Override    public void undo() { light.on(); }}++// 遥控器 - 调用者public class RemoteControl {    private Command[] onCommands = new Command[5];    private Command[] offCommands = new Command[5];        public void setCommand(int slot, Command onCommand, Command offCommand) {        onCommands[slot] = onCommand;        offCommands[slot] = offCommand;    }        public void onButton(int slot) {        if (onCommands[slot] != null) {            onCommands[slot].execute();        }    }        public void offButton(int slot) {        if (offCommands[slot] != null) {            offCommands[slot].execute();        }    }        public void undoButton() {        // 撤销    }}++// 使用public class Main {    public static void main(String[] args) {        Light livingRoomLight = new Light();        Command lightOn = new LightOnCommand(livingRoomLight);        Command lightOff = new LightOffCommand(livingRoomLight);                RemoteControl remote = new RemoteControl();        remote.setCommand(0, lightOn, lightOff);        remote.onButton(0);        remote.offButton(0);    }}```+### 16.5.2 订单系统++```java

+### 16.6.1 命令类膨胀+```java
+// 每个操作都需要一个命令类// 如果有100个操作，就需要100个命令类// 解决方案：使用lambda或参数化命令```++### 16.6.2 内存占用+```java
+// 撤销/重做需要保存所有命令// 可能占用大量内存// 解决方案：限制保存数量，或使用命令模式快照```+### 16.6.3 命令 vs 策略+| 特征 | 命令模式 | 策略模式 | |------|-----------|----------| | 目的 | 封装操作为可撤销 | 封装算法 | | 执行 | 可延迟、可排队 | 立即执行 | | 状态 | 可保存状态 | 通常无状态 |+### 16.6.4 与外观模式的区别+| 特征 | 命令模式 | 外观模式 | |------|-----------|----------| | 目的 | 封装操作为对象 | 简化接口 | | 关注点 | 操作 | 子系统 | | 撤销 | 支持 | 不支持 |+| 队列 | 支持 | 不支持 |+## 16.7 优化策略
+### 16.7.1 使用Lambda表达式+```java
