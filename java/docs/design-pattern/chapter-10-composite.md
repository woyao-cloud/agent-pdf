# 第10章 组合模式（Composite）
+**组合模式**将对象组合成树形结构以表示"部分-整体"的层次结构，使得用户对单个对象和组合对象的使用具有一致性。+## 10.1 解决的问题与应用场景
+### 10.1.1 问题分析
+在软件系统中，经常需要处理**树形结构**的数据：```java
+// 文件系统+根目录/│  ├─ 文件夹A/│  │  ├─ 文件1.txt│  │  └─ 文件2.txt│  └─ 文件夹B/│     ├─ 文件夹C/│     │  └─ 文件3.txt│     └─ 文件4.txt+```++如果用普通面向对象方式处理：- 不同的接口处理文件和文件夹- 需要大量if-else判断- 代码重复，难以维护++### 10.1.2 典型应用场景
++**1. 文件系统**```java
+FileSystemElement file = new File("readme.txt");FileSystemElement folder = new Folder("docs");folder.add(file);folder.remove(file);folder.getSize();  // 递归计算```++**2. 组织结构**```java
+Organization employee = new Employee("John", "Engineer");Organization department = new Department("Engineering");department.add(employee);department.getCost();  // 部门总成本```++**3. 图形界面**```java
+Component button = new Button();Component panel = new Panel();panel.add(button);panel.render();  // 渲染整个面板```++**4. 菜单系统**```java
+MenuItem menuItem = new MenuItem("Save");Menu subMenu = new Menu("File");subMenu.add(menuItem);subMenu.click();  // 触发所有菜单项```+## 10.2 实现原理与UML
+### 10.2.1 核心思想
+组合模式的核心是**让单个对象和组合对象具有相同的接口**，用户不需要关心处理的是单个对象还是组合对象。+### 10.2.2 UML类图+```┌─────────────────────┐│    Component       ││   (抽象组件)        │├─────────────────────┤│ + operation()      ││ + add(Component)   ││ + remove(Component)││ + getChild(int)    │└──────────┬──────────┘+           ▲+           │+    ┌──────┴──────┐+    │             │+    ▼             ▼+┌─────────────┐  ┌─────────────────┐+│    Leaf     │  │    Composite    │+│  (叶子节点)  │  │    (组合节点)    │+├─────────────┤  ├─────────────────┤+│ + operation()│  │ - children      │+└─────────────┘  │ + operation()   │+                 │ + add()         │+                 │ + remove()      │+                 │ + getChild()    │+                 └─────────────────┘+```+++### 10.2.3 角色分析+- **Component（抽象组件）**：为叶子节点和组合对象声明公共接口- **Leaf（叶子节点）**：表示组合中的叶子节点，实现Component接口- **Composite（组合节点）**：定义有子部件的组合部件的行为，存储子部件++### 10.2.4 时序图+```Client              Composite            Leaf+   │                  │                  │   │   operation()    │                  │   │ ──────────────►  │                  │   │                  │                  │   │                  │  (委托给子节点)   │   │                  │ ──────────────►  │   │                  │                  │   │                  │   result          │   │ ◄─────────────── │                  │   │                  │                  │```++## 10.3 代码实现
+### 10.3.1 透明组合模式+所有方法都定义在Component接口中，叶子节点也实现这些方法（空实现或抛出异常）。+```java
+// 抽象组件+public abstract class FileSystemElement {    protected String name;        public FileSystemElement(String name) {        this.name = name;    }        // 公共方法    public abstract long getSize();        public abstract void display(int depth);        // 组合相关方法（叶子节点也支持）    public void add(FileSystemElement element) {        throw new UnsupportedOperationException();    }        public void remove(FileSystemElement element) {        throw new UnsupportedOperationException();    }        public FileSystemElement getChild(int index) {        throw new UnsupportedOperationException();    }}++// 叶子节点 - 文件+public class File extends FileSystemElement {    private long size;        public File(String name, long size) {        super(name);        this.size = size;    }        @Override    public long getSize() {        return size;    }        @Override    public void display(int depth) {        System.out.println(indent(depth) + "- " + name + " (" + size + " bytes)");    }        // 空实现或异常    @Override    public void add(FileSystemElement element) {        // 不支持    }        @Override    public void remove(FileSystemElement element) {        // 不支持    }        @Override    public FileSystemElement getChild(int index) {        return null;    }        private String indent(int depth) {        StringBuilder sb = new StringBuilder();        for (int i = 0; i < depth; i++) {            sb. append("  ");        }        return sb.toString();    }}++// 组合节点 - 文件夹+public class Folder extends FileSystemElement {    private List<FileSystemElement> children = new ArrayList<>();        public Folder(String name) {        super(name);    }        @Override    public long getSize() {        long totalSize = 0;        for (FileSystemElement child : children) {            totalSize += child.getSize();        }        return totalSize;    }        @Override    public void display(int depth) {        System.out.println(indent(depth) + "+ " + name + " (" + getSize() + " bytes)");        for (FileSystemElement child : children) {            child.display(depth + 1);        }    }        @Override    public void add(FileSystemElement element) {        children.add(element);    }        @Override    public void remove(FileSystemElement element) {        children.remove(element);    }        @Override    public FileSystemElement getChild(int index) {        return children.get(index);    }        private String indent(int depth) {        StringBuilder sb = new StringBuilder();        for (int i = 0; i < depth; i++) {            sb.append("  ");        }        return sb.toString();    }}++// 使用+public class Main {    public static void main(String[] args) {        Folder root = new Folder("root");        Folder docs = new Folder("docs");        Folder images = new Folder("images");        File readme = new File("readme.txt", 1024);        File doc1 = new File("doc1.md", 2048);        File pic1 = new File("pic1.jpg", 4096);        File pic2 = new File("pic2.png", 8192);                docs.add(doc1);        docs.add(readme);        images.add(pic1);        images.add(pic2);        root.add(docs);        root.add(images);                root.display(0);        System.out.println("Total size: " + root.getSize() + " bytes");    }}```+输出：```+root (15360 bytes)  + docs (3072 bytes)    - doc1.md (2048 bytes)    - readme.txt (1024 bytes)  + images (12288 bytes)    - pic1.jpg (4096 bytes)    - pic2.png (8192 bytes)Total size: 15360 bytes```+### 10.3.2 安全组合模式+将组合相关方法定义在Composite中，不在Component中声明。+```java
+// 抽象组件 - 只声明公共方法+public abstract class FileSystemElement {    protected String name;        public FileSystemElement(String name) {        this.name = name;    }        public abstract long getSize();    public abstract void display(int depth);}++// 叶子节点+public class File extends FileSystemElement {    private long size;        public File(String name, long size) {        super(name);        this.size = size;    }        @Override    public long getSize() {        return size;    }        @Override    public void display(int depth) {        System.out.println(indent(depth) + "- " + name);    }        private String indent(int depth) {        return "  ". repeat(depth);    }}++// 组合节点 - 添加组合方法+public class Folder extends FileSystemElement {    private List<FileSystemElement> children = new ArrayList<>();        public Folder(String name) {        super(name);    }        // 组合方法    public void add(FileSystemElement element) {        children.add(element);    }        public void remove(FileSystemElement element) {        children.remove(element);    }        public FileSystemElement getChild(int index) {        return children.get(index);    }        @Override    public long getSize() {        return children.stream().mapToLong(FileSystemElement::getSize).sum();    }        @Override    public void display(int depth) {        System.out.println(indent(depth) + "+ " + name);        for (FileSystemElement child : children) {            child.display(depth + 1);        }    }        private String indent(int depth) {        return "  ". repeat(depth);    }}++// 客户端代码需要判断类型+public class Main {    public static void main(String[] args) {        Folder root = new Folder("root");        // ...        // 需要强制转换为Folder才能添加        if (root instanceof Folder) {            ((Folder) root).add(new File("test.txt", 100));        }    }}```++### 10.3.3 组合模式 + 迭代器+```java

+### 10.6.1 透明性vs安全性+**透明组合模式**：+ - 优点：接口统一，客户端代码简单+ - 缺点：叶子节点需要空实现或异常+**安全组合模式**：+ - 优点：叶子节点不会有不支持的方法+ - 缺点：客户端需要判断类型++### 10.6.2 递归遍历的性能问题+深层嵌套的组合结构可能导致栈溢出或性能问题。++**解决方案**：+- 使用迭代而非递归+- 添加深度限制+- 使用懒加载++### 10.6.3 设计复杂度+对于简单场景，组合模式可能过度设计。++**解决方案**：+- 树形结构不明确时不用+- 层级少且固定时不用++### 10.6.4 违反开闭原则+如果Component需要添加新方法，所有实现类都需要修改。++**解决方案**：+- 使用默认方法（Java 8+）+- 谨慎设计Component接口+## 10.7 优化策略
+### 10.7.1 使用Java 8默认方法+```java+public abstract class FileSystemElement {    public void add(FileSystemElement element) {        throw new UnsupportedOperationException();    }        // Java 8后可用默认方法    public void addDefault(FileSystemElement element) {        throw new UnsupportedOperationException();    }}```++### 10.7.2 缓存机制+```java+public class Folder extends FileSystemElement {    private Long cachedSize;        @Override    public long getSize() {        if (cachedSize == null) {            cachedSize = children.stream()                .mapToLong(FileSystemElement::getSize)                .sum();        }        return cachedSize;    }        public void invalidateCache() {        cachedSize = null;        children.forEach(c -> {            if (c instanceof Folder) {                ((Folder) c).invalidateCache();            }        });    }}```++### 10.7.3 访问者模式结合+组合模式常与访问者模式结合：+```java+// Visitor定义访问操作public interface Visitor {    void visitFile(File file);    void visitFolder(Folder folder);}++// 在Component中accept方法+public abstract void accept(Visitor visitor);```++### 10.7.4 最佳实践+| 场景 | 推荐方式 | |------|----------| | 树形结构 | 组合模式 | | 层级简单 | 直接实现 | | 需要统一接口 | 透明模式 | | 需要类型安全 | 安全模式 |+## 本章小结
