# 第20章 观察者模式（Observer）
+**观察者模式**定义对象间的一对多依赖关系，当一个对象的状态发生改变时，所有依赖于它的对象都得到通知并被自动更新。+## 20.1 解决的问题与应用场景+### 20.1.1 问题分析+当一个对象的状态变化需要通知多个其他对象时，如果不使用观察者模式：+```java+// 被观察者需要持有所有观察者引用+public class Subject {    private List<Observer> observers = new ArrayList<>();    // 需要手动通知每个观察者    private void notifyAll() {        for (Observer o : observers) {            o.update(this);        }    }}```+### 20.1.2 典型应用场景+**1. 事件监听**```java+button.addActionListener(e -> handleClick());```+**2. 消息推送**```java+eventBus.post(new MessageEvent());```+**3. 数据绑定**```java+// UI组件与数据模型同步```+**4. 分布式事件**```java+// 消息队列系统```+## 20.2 实现原理与UML+```┌─────────────────┐        ┌─────────────────┐│    Subject     │        │   Observer      ││   (主题)       │        │   (观察者)      │├─────────────────┤        ├─────────────────┤│ - observers    │────────│ + update()     ││ + attach()     │        └─────────────────┘│ + detach()     │                ││ + notify()     │                │└─────────────────┘                │         ┌────────┴────────┐         │         ▼                  │┌─────────────────┐  ┌─────────────────┐│ConcreteSubject │  │ConcreteObserver ││ (具体主题)      │  │ (具体观察者)    │├─────────────────┤  ├─────────────────┤│ - state        │  │ + update()     ││ + getState()   │  └─────────────────┘│ + setState()   │```+## 20.3 代码实现+### 20.3.1 基础实现++```java
