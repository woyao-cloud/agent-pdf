# 第24章 访问者模式（Visitor）
+**访问者模式**表示一个作用于某对象结构中的各元素的操作。可以在不改变各元素的类的前提下定义作用于这些元素的新操作。+## 24.1 解决的问题与应用场景+### 24.1.1 问题分析+对象结构稳定，但需要对其元素进行多种不同操作：```java// 员工结构：经理、工程师、销售// 需要：计算薪资、统计工时、打印报表// 如果在每个员工类中实现，会违反单一职责```+### 24.1.2 典型应用场景+**1. 编译器**```java// AST节点：需要类型检查、优化、代码生成```+**2. 文件系统**```java// 文件/文件夹：需要统计大小、搜索、压缩```+## 24.2 实现原理+```java// 元素接口public interface Element {    void accept(Visitor visitor);}++// 访问者接口public interface Visitor {    void visitElementA(ElementA element);    void visitElementB(ElementB element);}++// 具体元素public class ConcreteElementA implements Element {    @Override    public void accept(Visitor visitor) {        visitor.visitElementA(this);    }}```+## 24.3 代码实现+### 24.3.1 员工薪资计算++```java
+// 员工元素public abstract class Employee {    private String name;    private double salary;        public abstract void accept(Visitor visitor);        // getters/setters}++public class Engineer extends Employee {    @Override    public void accept(Visitor visitor) {        visitor.visitEngineer(this);    }}++public class Manager extends Employee {    @Override    public void accept(Visitor visitor) {        visitor.visitManager(this);    }}++// 访问者 - 计算薪资public class SalaryVisitor implements Visitor {    private double totalSalary = 0;        @Override    public void visitEngineer(Engineer e) {        totalSalary += e.getSalary();    }        @Override    public void visitManager(Manager m) {        totalSalary += m.getSalary() * 1.2;  // 经理有奖金    }        public double getTotal() { return totalSalary; }}++// 使用List<Employee> employees = getEmployees();SalaryVisitor visitor = new SalaryVisitor();for (Employee e : employees) {    e.accept(visitor);}System.out.pringt("总薪资: " + visitor.getTotal());```+## 24.4 本章小结
+访问者模式将操作与对象结构分离，在不修改元素类的情况下添加新操作。适用于对象结构稳定但操作常变的场景。
