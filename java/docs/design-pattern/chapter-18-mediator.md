# 第18章 中介者模式（Mediator）
+**中介者模式**定义一个封装一组对象如何交互的对象。通过使对象明确地相互引用但松散耦合，促进行为的更改和可伸缩性。+## 18.1 解决的问题与应用场景+### 18.1.1 问题分析+```java+// 多个对象相互引用，形成复杂的依赖关系// 对象A -> 对象B -> 对象C -> 对象D// 问题：// - 对象间耦合紧密// - 一个对象变化会影响多个对象// - 难以维护和扩展```+### 18.1.2 典型应用场景+**1. GUI组件通信**```java+// 按钮点击后更新文本框、列表等// 不直接调用，而是通过中介者```+**2. 聊天室**```java+// 用户发送消息，聊天室转发给所有其他用户```+**3. 机场调度**```java+// 调度中心协调各航班起降```+## 18.2 实现原理与UML+```┌──────────┐     ┌──────────────────┐     ┌──────────┐│Component│     │    Mediator     │     │Component│├──────────┤     │   (中介者)       │     ├──────────┤│-mediator │────►│ + notify()       │◄────│-mediator │└──────────┘     └──────────────────┘     └──────────┘     ▲          │     │          │     ▼          │     ▼     │┌──────────┐  │     ┌──────────────────┐  ┌──────────┐│ComponentA│  │     │ConcreteMediator │  │ComponentB│└──────────┘  │     ├──────────────────┤  └──────────┘└──────────┘     │ - componentA      │                │                │ - componentB      │                └──────────────────┘```+## 18.3 代码实现+### 18.3.1 聊天室示例++```java
