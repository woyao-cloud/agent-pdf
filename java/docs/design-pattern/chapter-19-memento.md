+**备忘录模式**在不破坏封装性的前提下，捕获一个对象的内部状态，并在这个对象之外保存这个状态。这样以后就可将该对象恢复到原先保存的状态。+## 19.1 解决的问题与应用场景+### 19.1.1 问题分析+```java+// 需要保存对象的状态，以便恢复// 问题：// - 直接访问对象内部会破坏封装性// - 难以记录多个历史状态```+### 19.1.2 典型应用场景+**1. 撤销功能**```java+// 游戏存档、编辑器撤销```+**2. 事务回滚**```java+// 数据库事务的回滚点```+**3. 快照**```java+// 系统状态快照```+## 19.2 实现原理与UML+```┌─────────┐     ┌─────────────────┐     ┌─────────────┐│Originator│     │    Memento     │     │  Caretaker  ││(原发者)  │     │    (备忘录)     │     │  (管理者)   │├─────────┤     ├─────────────────┤     ├─────────────┤│- state  │────►│ - state        │     │- memento  ││+ save() │     │ + getState()   │     │ + save()    ││+ restore()│   │ + setState()   │     │ + restore() │└─────────┘     └─────────────────┘     └─────────────┘```+## 19.3 代码实现+### 19.3.1 基础实现++```java
