# 第21章 状态模式（State）
+**状态模式**允许对象在内部状态改变时改变它的行为。对象看起来好像修改了它的类。+## 21.1 解决的问题与应用场景+### 21.1.1 问题分析+```java
+// 订单状态：待支付 -> 已支付 -> 已发货 -> 已完成+// 使用if-else实现：public void handle() {    if (status.equals("待支付")) {        // 处理待支付    } else if (status.equals("已支付")) {        // 处理已支付    } else if (status.equals("已发货")) {        // 处理已发货    }    // 问题：状态多时if-else嵌套深，违反开闭原则```+### 21.1.2 典型应用场景+**1. 订单状态机**```java+// 订单状态转换OrderContext context = new OrderContext();context.setState(new PendingState());context.handle();  // 等待支付context.setState(new PaidState());context.handle();  // 已支付```+**2. 游戏角色状态**```java+// 角色状态：正常 -> 虚弱 -> 中毒 -> 死亡```+**3. 电梯控制系统**```java+// 电梯状态：开门 -> 关门 -> 运行 -> 停止```+## 21.2 实现原理与UML+```┌───────────────┐       ┌─────────────────┐│   Context     │       │     State      ││   (上下文)     │       │   (抽象状态)    │├───────────────┤       ├─────────────────┤│ - state       │──────►│ + handle()     ││ + request()   │       └────────┬────────┘│ + setState()  │                │       ┌───────┴───────┐       │       ▼               ▼┌───────────────┐   ┌─────────────────┐│ConcreteStateA │   │ConcreteStateB  ││  (具体状态A)   │   │  (具体状态B)   │├───────────────┤   ├─────────────────┤│ + handle()    │   │ + handle()     │└───────────────┘   └─────────────────┘```+## 21.3 代码实现+### 21.3.1 订单状态示例++```java
