# 第23章 模板方法模式（Template Method）
+**模板方法模式**定义一个算法骨架，将某些步骤延迟到子类中实现。+## 23.1 解决的问题与应用场景+### 23.1.1 问题分析+算法结构固定，但某些步骤需要不同实现：```java// 流程：连接 -> 查询 -> 处理 -> 关闭// 公共部分在父类，具体实现在子类```+### 23.1.2 典型应用场景+**1. 框架设计**```java// Spring JDBC Template：定义流程，子类实现SQL```+**2. 业务处理流程**```java// 订单处理：验证 -> 扣库存 -> 支付 -> 发货 -> 通知```+## 23.2 实现原理+```java// 抽象类public abstract class AbstractClass {    // 模板方法    public final void templateMethod() {        step1();        step2();        step3();    }        protected abstract void step1();    protected abstract void step2();    protected void step3() {  // 默认实现        // 可选覆盖    }}```+## 23.3 代码实现+### 23.3.1 制作饮料++```java
