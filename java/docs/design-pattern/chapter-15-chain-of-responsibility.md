# 第15章 责任链模式（Chain of Responsibility）
+**责任链模式**将请求的发送者和接收者解耦，使多个对象都有机会处理请求。将这些对象连成一条链，并沿着这条链传递请求，直到有一个对象处理它为止。
+## 15.1 解决的问题与应用场景
+### 15.1.1 问题分析
+在软件系统中，经常需要处理一系列的请求，每个请求可能需要不同的处理逻辑：```java+// 假设用户请求需要经过：// 1. 身份验证 -> 如果未登录，拒绝// 2. 权限验证 -> 如果无权限，拒绝// 3. 参数验证 -> 如果参数错误，拒绝// 4. 业务处理 -> 处理请求+// 问题：+// - if-else 嵌套层级深// - 新增或删除处理逻辑需要修改代码// - 处理顺序变化困难```+### 15.1.2 典型应用场景++**1. 过滤器链**```java+// Web请求过滤器AuthFilter -> LoggingFilter -> ValidationFilter -> Controller```++**2. 审批流程**```java+// 费用审批ChainManager -> DepartmentHead -> CFO -> CEO```++**3. 异常处理**```java+// 异常捕获catch(FileNotFoundException e) { }catch(IOException e) { }catch(Exception e) { }```++**4. 事件处理**```java
+// GUI事件冒泡button.addActionListener(listener1);button.addActionListener(listener2);```+## 15.2 实现原理与UML
+### 15.2.1 核心思想
+责任链模式的核心是**将处理请求的对象连成一条链，请求沿着链传递，直到有对象处理它为止**。每个处理者可以决定是否处理请求，或者将请求传递给下一个处理者。+### 15.2.2 UML类图+```┌─────────────────────┐│   Handler           ││  (抽象处理者)       │├─────────────────────┤│ - successor         │├─────────────────────┤│ + setSuccessor()    ││ + handleRequest()   │└──────────┬──────────┘           ▲           │    ┌──────────┴──────────┐    │                     │    ▼                     ▼┌─────────────────┐  ┌─────────────────┐│ConcreteHandler1│  │ConcreteHandler2││ (具体处理者1)   │  │ (具体处理者2)   │├─────────────────┤  ├─────────────────┤│ + handleRequest│  │ + handleRequest│└─────────────────┘  └─────────────────┘```+++### 15.2.3 角色分析+- **Handler（抽象处理者）**：定义处理请求的接口，维护一个后继者的引用- **ConcreteHandler（具体处理者）**：处理它所负责的请求，可访问它的后继者- **Client（客户端）**：向链上的第一个处理者对象提交请求+### 15.2.4 时序图+```Client         Handler1           Handler2           Handler3+   │                │                  │                  │   │                │                  │                  │   │ handleRequest │                  │                  │   │ ────────────► │                  │                  │   │                │                  │                  │   │                │ (处理/转发)      │                  │   │                │ ───────────────►│                  │   │                │                  │                  │   │                │                  │   (处理)         │   │                │                  │ ──────────────►  │   │                │                  │                  │   │                │                  │   result         │   │ ◄──────────────│◄────────────────│◄─────────────────│   │                │                  │                  │```++## 15.3 代码实现
