# 第17章 迭代器模式（Iterator）
+**迭代器模式**提供一种方法顺序访问集合对象中的各个元素，而不暴露其底层表示。它是一种行为型设计模式。+## 17.1 解决的问题与应用场景+### 17.1.1 问题分析+```java+// 遍历集合的传统方式：for (int i = 0; i < list.size(); i++) {    Object obj = list.get(i);}// 问题：+// - 不同的集合类型有不同的遍历方式+// - 客户端需要了解集合的内部结构+// - 难以统一遍历接口```+### 17.1.2 典型应用场景+**1. 统一遍历接口**```java+Iterator it = collection.iterator();while (it.hasNext()) {    Object obj = it.next();}```+**2. 多种遍历方式**```java+// 顺序遍历ListIterator it = list.listIterator();// 逆序遍历Iterator reverseIt = list.descendingIterator();```+**3. 透明遍历**```java+// 不关心底层是List还是Setfor (Item item : items) {    process(item);}```+## 17.2 实现原理与UML+```┌─────────────┐        ┌─────────────────┐│  Aggregate  │        │   Iterator      ││ (集合)      │        │  (迭代器)       │├─────────────┤        ├─────────────────┤│ +createIterator()│      │+ hasNext()     │└──────┬──────┘        │ + next()        │        ├─────────────────┘        │                │        │                │        ▼                │┌─────────────┐        │        │┌─────────────┐│ConcreteAgg  │◄───────┘        ││(具体集合)    │               │        ││+createIterator()│             │        │└─────────────┘               │        ▼                │┌─────────────────┐               ││ConcreteIterator │◄──────────────┘│(具体迭代器)     │├─────────────────┤│ + hasNext()     ││ + next()        │└─────────────────┘```+## 17.3 代码实现+### 17.3.1 基础实现++```java
+// 迭代器接口+public interface Iterator<E> {    boolean hasNext();    E next();}++// 集合接口+public interface Container<E> {    Iterator<E> iterator();}++// 具体迭代器+public class ArrayIterator<E> implements Iterator<E> {    private E[] array;    private int position = 0;        public ArrayIterator(E[] array) {        this.array = array;    }        @Override    public boolean hasNext() {        return position < array.length;    }        @Override       public E next() {        return array[position++];    }}++// 具体集合+public class ArrayContainer<E> implements Container<E> {    private E[] array;        public ArrayContainer(E[] array) {        this.array = array;    }        @Override    public Iterator<E> iterator() {        return new ArrayIterator<>(array);    }}++// 使用+public class Main {    public static void main(String[] args) {        String[] names = {"Alice", "Bob", "Charlie"};        Container<String> container = new ArrayContainer<>(names);        Iterator<String> it = container.iterator();                while (it.hasNext()) {            System.out.println(it.next());        }    }}```++### 17.3.2 双向迭代器++```java
+public interface ListIterator<E> extends Iterator<E> {    boolean hasPrevious();    E previous();    void remove();}```+## 17.4 JDK源码解析+### 17.4.1 Collection迭代器+```java
+// java.util.Iteratorpublic interface Iterator<E> {    boolean hasNext();    E next();    default void remove() {        throw new UnsupportedOperationException("remove");    }    default void forEachRemaining(Consumer<? super E> action) {        while (hasNext()) {            action.accept(next());        }    }}```++### 17.4.2 For-each循环+```java+// 增强for循环底层使用迭代器for (String s : list) {    System.out.println(s);}```+### 17.4.3 ListIterator+```java
+public interface ListIterator<E> extends Iterator<E> {    void add(E e);    void set(E e);    void remove();    int nextIndex();    int previousIndex();    boolean hasPrevious();    E previous();}```+## 17.5 本章小结
+迭代器模式提供统一的遍历接口，封装集合的内部结构，使客户端可以透明地遍历不同类型的集合。Java的Collection框架提供了完整的迭代器实现。
