# 第1章 数据结构概述

## 1.1 什么是数据结构

**数据结构（Data Structure）** 是计算机存储、组织数据的方式。精心选择的数据结构可以带来最优化的算法效率。

### 数据的逻辑结构

数据元素之间存在的逻辑关系：

| 结构名称 | 结构描述 | 典型例子 |
|---------|---------|----------|
| **集合** | 数据元素同属于一个集合，无其他关系 | Set |
| **线性结构** | 数据元素之间存在一对一关系 | 数组、链表、栈、队列 |
| **树形结构** | 数据元素之间存在一对多关系 | 二叉树、B树 |
| **图结构** | 数据元素之间存在多对多关系 | 社交网络、路由图 |

### 数据的物理结构

数据在内存中的实际存储方式：

| 存储方式 | 特点 | 优点 | 缺点 |
|---------|------|------|------|
| **顺序存储** | 连续内存地址 | 查询快O(1) | 插入删除慢 |
| **链式存储** | 指针链接 | 插入删除快O(1) | 查询慢 |
| **索引存储** | 额外索引表 | 查询快 | 占用额外空间 |
| **散列存储** | 哈希计算位置 | 查询快 | 存在哈希冲突 |

## 1.2 数据结构的重要性

### 为什么数据结构如此重要？

1. **程序性能的核心**
   - 优秀的数据结构能让算法快1000倍
   - 错误的选择导致系统无法扩展

2. **工程质量的基石**
   - 合理的数据结构使代码更简洁
   - 降低维护成本，提高可读性

3. **解决问题的能力**
   - 面对新问题知道如何建模
   - 选择最合适的技术方案

### 数据结构 vs 算法

| 维度 | 数据结构 | 算法 |
|------|----------|------|
| 定义 | 数据的组织方式 | 解决问题的步骤 |
| 关系 | 算法操作的对象 | 操作数据的方法 |
| 核心问题 | 如何存储 | 如何处理 |

> **名言**：程序 = 数据结构 + 算法 —— Pascal语言创始人 Niklaus Wirth

## 1.3 常见数据结构分类

### 按逻辑结构分类

```
数据结构
├── 线性结构
│   ├── 数组（Array）
│   ├── 链表（Linked List）
│   ├── 栈（Stack）
│   ├── 队列（Queue）
│   └── 散列表（Hash Table）
├── 树形结构
│   ├── 二叉树（Binary Tree）
│   ├── 二叉搜索树（BST）
│   ├── 平衡树（AVL、红黑树）
│   ├── B树/B+树
│   └── Trie树
├── 图结构
│   ├── 有向图/无向图
│   ├── 加权图/无权图
│   └── 稠密图/稀疏图
└── 其他结构
    ├── 堆（Heap）
    ├── 并查集（Union-Find）
    ├── 跳表（Skip List）
    └── 线段树（Segment Tree）
```

### 按操作复杂度分类

| 类别 | 数据结构 | 查找 | 插入 | 删除 |
|------|----------|------|------|------|
| **数组** | Array | O(1) | O(n) | O(n) |
| **链表** | LinkedList | O(n) | O(1) | O(1) |
| **栈** | Stack | - | O(1) | O(1) |
| **队列** | Queue | - | O(1) | O(1) |
| **哈希表** | HashMap | O(1) | O(1) | O(1) |
| **二叉搜索树** | TreeMap | O(log n) | O(log n) | O(log n) |
| **平衡二叉树** | TreeSet | O(log n) | O(log n) | O(log n) |
| **堆** | PriorityQueue | O(1) | O(log n) | O(log n) |

## 1.4 Java中的数据结构生态

### Java集合框架（JCF）

Java SE提供了一套完善的数据结构实现，位于`java.util`包：

```
Collection接口
├── List接口（有序、可重复）
│   ├── ArrayList（数组实现）
│   ├── LinkedList（链表实现）
│   ├── Vector（线程安全）
│   └── Stack（栈）
├── Set接口（无序、不重复）
│   ├── HashSet（哈希表）
│   ├── LinkedHashSet（保持插入顺序）
│   ├── TreeSet（红黑树）
│   └── EnumSet（枚举类型）
└── Queue接口（队列）
    ├── LinkedList（可做双端队列）
    ├── PriorityQueue（优先级队列）
    ├── ArrayDeque（数组双端队列）
    └── BlockingQueue（阻塞队列）

Map接口（键值对）
├── HashMap（哈希表）
├── LinkedHashMap（保持插入顺序）
├── TreeMap（红黑树）
├── Hashtable（线程安全）
├── ConcurrentHashMap（并发哈希表）
└── WeakHashMap（弱引用）
```

### 并发数据结构

| 线程安全实现 | 使用场景 |
|-------------|---------|
| ConcurrentHashMap | 高并发缓存 |
| CopyOnWriteArrayList | 读多写少 |
| BlockingQueue | 生产者-消费者 |
| ConcurrentLinkedQueue | 无界队列 |
| SynchronousQueue | 线程同步 |

### 特殊数据结构

| 数据结构 | Java实现 | 用途 |
|---------|----------|------|
| 栈 | Deque/Stack | 表达式求值 |
| 队列 | Queue/Deque | 任务调度 |
| 优先队列 | PriorityQueue | TopK问题 |
| 跳表 | ConcurrentSkipListMap | 有序并发Map |
| 不可变集合 | Collections.unmodifiable* | 防御式编程 |

## 1.5 如何学习数据结构

### 学习路径

```
第一阶段：理解原理
├── 了解每种结构的特点
├── 理解适用场景
└── 掌握时间空间复杂度

第二阶段：代码实现
├── 手写核心方法
├── 分析源码实现
└── 理解设计思想

第三阶段：应用实践
├── 实际项目中使用
├── 性能调优
└── 问题排查

第四阶段：融会贯通
├── 组合使用多种结构
├── 设计新数据结构
└── 解决新问题
```

### 学习方法

1. **动手实现**：不要只看，要自己写一遍
2. **对比分析**：比较相似结构的优劣
3. **问题驱动**：带着问题学习
4. **源码阅读**：学习优秀的实现
5. **实际应用**：在项目中使用

### 常见误区

| 误区 | 正确认识 |
|------|----------|
| 学完就忘 | 反复练习，周期复习 |
| 只看不写 | 必须动手实践 |
| 追求难题 | 掌握基础更重要 |
| 死记硬背 | 理解原理是关键 |
| 纸上谈兵 | 要在项目中应用 |
