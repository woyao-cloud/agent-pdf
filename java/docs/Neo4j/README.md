# Neo4j 图数据库：原理、实践与 DeepSeek 集成

> 从图存储到 Graph RAG 的完整指南

## 书籍定位

本书面向中高级 Java/Python 后端开发工程师、数据工程师、架构师和 AI 工程师，系统讲解 Neo4j 图数据库的原理、实践与 DeepSeek 大模型集成。内容覆盖从 Neo4j 基础架构到 Graph RAG 完整实现的全栈知识体系。
