# 图数据库：原理、实践与架构设计

> 从图论基础到分布式图存储，从Neo4j到LLM集成

## 书籍定位

本书面向中高级 Java/后端开发工程师、架构师和数据工程师，系统讲解图数据库的原理、实践与架构设计。内容覆盖从图论基础到主流图数据库深度解析，再到图神经网络与 LLM 集成的前沿实践。
