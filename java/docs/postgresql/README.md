# 精通PostgreSQL（Java版）

> 场景·原理·实战·优化

## 书籍定位

本书面向Java后端工程师、全栈开发者、架构师及初级DBA，**以场景驱动**的方式系统讲解PostgreSQL的核心优势、实现原理、潜在风险和优化策略。每一个场景都配有完整的Docker Compose环境和Java示例代码，可本地运行验证。

## 整体结构

```
精通PostgreSQL（Java版）
├── 基础篇：PostgreSQL基础（第1-4章）
├── 场景篇：15大核心场景（第5-19章）
├── 进阶篇：风险与优化（第20-23章）
└── 技能篇：开发者必备（第24-26章）
```

## 场景速查

| 场景 | 适用场景 | 核心价值 |
|------|---------|---------|
| 高效CRUD | 批量导入、UPSERT | COPY协议提速10倍 |
| 复杂查询 | 树形结构、窗口分析 | 递归CTE + 窗口函数 |
| 索引优化 | 查询性能调优 | 6种索引类型选择 |
| 全文搜索 | 站内搜索、轻量ES替代 | tsvector + GIN索引 |
| JSON/NoSQL | 灵活Schema设计 | JSONB + GIN索引 |
| PostGIS | 地理空间查询 | 专业级GIS功能 |
| 时序数据 | IoT、监控数据 | 分区+BRIN索引 |
| 分区表 | 大数据量管理 | 声明式分区 |
| 触发器/事件 | 数据同步 | LISTEN/NOTIFY |
| 物化视图 | 报表加速 | 预计算快照 |
| FDW | 跨库查询 | 数据联邦 |
| 逻辑复制 | 数据分发 | 发布/订阅 |
| 连接池 | 高并发 | PgBouncer |
| 备份恢复 | 灾备 | PITR时间点恢复 |
| 高可用 | 零宕机升级 | Patroni + etcd |

## 环境要求

- JDK 17+
- Docker & Docker Compose
- PostgreSQL 15/16
- Spring Boot 3.x
