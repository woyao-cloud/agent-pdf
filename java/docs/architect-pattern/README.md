## 写作规范

1. **代码格式**：使用标准缩进，保持代码可读性
2. **架构图**：使用文本图形或 Mermaid 图表
3. **示例代码**：使用 Java 作为主要示例语言
4. **内容深度**：理论 + 实践相结合
