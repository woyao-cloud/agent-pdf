# 第12章 架构师必备技能
## 12.1 技术能力
### 12.1.1 技术广度
- 掌握多种编程语言
- 了解主流框架
- 熟悉基础设施
- 跟踪新技术趋势
### 12.1.2 系统设计能力
- 需求分析
- 架构设计
- 技术选型
- 性能优化
- 容错设计
## 12.2 业务能力
- 深入理解业务
- 抽象业务模型
- 平衡业务与技术
- 领域驱动设计
## 12.3 沟通能力
- 技术方案讲解
- 跨团队协调
- 向上管理
- 知识传递
## 12.4 文档能力
### 12.4.1 架构设计文档
```markdown
# 架构设计文档
## 1. 概述
## 2. 架构设计
## 3. 技术选型
## 4. 部署方案
## 5. 性能评估
## 6. 风险分析
```### 12.4.2 ADR架构决策记录
```markdown
# ADR-001: 使用微服务架构
## 状态: 已通过
## 决策: 采用微服务架构
## 后果: 增加了系统复杂性， 但提高了可扩展性和团队效率
```## 12.5 架构治理
- 制定架构规范
- 代码审查
- 技术债务管理
- 架构适应性评估
## 12.6 本章小结
优秀架构师需要技术、 业务、 沟通三方面能力， 并持续学习和实践。 架构不是一成不变的， 需要根据业务发展不断演进。
