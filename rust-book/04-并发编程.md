# 第 4 章 并发编程
> **本章导读**：Rust 的并发模型——线程、消息传递、共享状态。Rust 的并发安全在编译期保证，这是它最大的优势之一。
## 1. 并发基础概念
### 1.1 进程 vs 线程
- **进程**：独立地址空间，通信需要 IPC
- **线程**：共享进程地址空间，通信简单但需同步
### 1.2 Rust 的并发哲学
> "默认安全，并发安全" —— Rust 编译器保证数据竞争（data race）在编译期被检测。
**数据竞争**：两个或更多指针同时访问同一数据，至少有一个在写，且没有同步。
```rust
// ❌ 编译错误！数据竞争
let mut data = vec![1, 2, 3];
let handles: Vec<_> = (0..3).map(|_| {
    std::thread::spawn(|| {
        data.push(4);  // 多个线程写同一个 vec
    })
}).collect();
```
编译器报错：```
error[E0502]: cannot borrow `data` as mutable more than once simultaneously
```
## 2. 线程（Thread）
### 2.1 创建线程
```rust
use std::thread;
use std::time::Duration;

fn main() {    // 创建线程
    let handle = thread::spawn(|| {        println!("Hello from new thread!");
    });    // 等待线程结束
    handle.join().unwrap();
}
```### 2.2 线程闭包捕获环境
```rust
fn main() {
    let v = vec![1, 2, 3];    let handle = thread::spawn(move || {  // move 转移所有权
        println!("Vector: {:?}", v);    });
    
    // println!("{:?}", v);  // ❌ 编译错误！v 已移动    handle.join().unwrap();
}
```### 2.3 线程返回值
```rust
fn main() {    let handle = thread::spawn(|| {        return 42;
    });
    let result = handle.join().unwrap();
    println!("Result: {}", result);  // 42
}
```### 2.4 线程 PANIC 处理
```rust
fn main() {    let handle = thread::spawn(|| {
        panic!("oops!");    });    let result = handle.join();    match result {        Ok(_) => println!("Success"),        Err(e) => println!("Panicked: {:?}", e),    }}
```
## 3. 消息传递（Message Passing）### 3.1 Channel
Rust 的消息传递通过 `mpsc`（多生产者，单消费者）实现：```rust
use std::sync::mpsc;
use std::thread;
use std::time::Duration;

fn main() {    let (tx, rx) = mpsc::channel();    // 发送者
    let tx1 = tx.clone();
    
    thread::spawn(move || {        tx.send("Hello").unwrap();    });
    
    thread::spawn(move || {        tx1.send("World").unwrap();    });
    
    // 接收
    for received in rx {        println!("Got: {}", received);    }
}
```### 3.2 通道特性
| 特性 | 说明 |
|------|------| | 发送方 | `send(T) -> Result<(), SendError<T>>` |
| 接收方 | `recv() -> Result<T, RecvError>` |
| 非阻塞 | `try_recv()` / `recv_timeout()` |
| 迭代器 | `for msg in rx {}` |
### 3.3 多个生产者
```rust
use std::sync::mpsc;
use std::thread;

fn main() {    let (tx, rx) = mpsc::channel();
    
    // 创建多个发送者    for i in 0..3 {        let tx = tx.clone();
        thread::spawn(move || {            tx.send(i).unwrap();        });    }    // 关闭 clone，原始 tx 才会被 drop
    
    // 收集所有消息    let mut results = vec![];
    for received in rx {        results.push(received);
        if results.len() == 3 {            break;
        }
    }    println!("{:?}", results);
}
```
## 4. 共享状态（Shared State）### 4.1 Mutex（互斥锁）
```rust
use std::sync::Mutex;
use std::thread;

fn main() {    let counter = Mutex::new(0);    let mut handles = vec![];
    
    for _ in 0..10 {        let handle = thread::spawn(move || {            let mut num = counter.lock().unwrap();            *num += 1;        });        handles.push(handle);    }    for handle in handles {        handle.join().unwrap();
    }    println!("Result: {}", *counter.lock().unwrap());  // 10}
```> ✅ **安全**：Mutex 内部有借用检查，编译期防止数据竞争。### 4.2 多线程使用 Rc vs Arc
```rust
use std::sync::{Arc, Mutex};
use std::thread;

fn main() {    // Arc: 原子引用计数，可跨线程共享    let counter = Arc::new(Mutex::new(0));    let mut handles = vec![];
    
    for _ in 0..10 {        let counter = Arc::clone(&counter);        let handle = thread::spawn(move || {            let mut num = counter.lock().unwrap();
            *num += 1;        });        handles.push(handle);    }    for handle in handles {        handle.join().unwrap();    }    println!("{}", *counter.lock().unwrap());}
```### 4.3 RwLock（读写锁）
```rust
use std::sync::RwLock;

fn main() {    let lock = RwLock::new(5);    {        let r = lock.read().unwrap();        println!("Read: {}", *r);    }    {        let mut w = lock.write().unwrap();        *w = 10;    }
}
```
## 5. Send + Sync trait
### 5.1 什么是 Send/Sync
- `Send`：值的所有权可在线程间转移
- `Sync`：值的引用可在线程间共享（`&T` 是 Send）
### 5.2 编译器自动派生
```rust
// 手动实现（通常不需要）
unsafe impl Send for MyType {}unsafe impl Sync for MyType {}
```> ⚠️ **警告**：手动实现 Send/Sync 需要确保线程安全。### 5.3 不是 Send 的例子
```rust
use std::rc::Rc;let rc = Rc::new(5);
// rc 不是 Send（引用计数不是线程安全的）
```## 6. 并发原语对比
| 原语 | 场景 | 特点 |
|------|------|------|
| `thread::spawn` | 创建工作线程 | 轻量 |
| `mpsc::channel` | 消息传递 | 所有权清晰 |
| `Mutex<T>` | 共享状态 | 独占访问 |
| `RwLock<T>` | 读多写少 | 读共享，写独占 |
| `Arc<T>` | 引用计数 | 线程安全 |
| `Atomic*` | 计数器 | 无锁 |
## 7. 原子类型
```rust
use std::sync::atomic::{AtomicUsize, Ordering};

fn main() {    static COUNTER: AtomicUsize = AtomicUsize::new(0);    COUNTER.fetch_add(1, Ordering::SeqCst);    println!("{}", COUNTER.load(Ordering::SeqCst));
}
```> ⚠️ **注意**：仅在确实需要无锁并发时使用原子。
