# 《精通 Rust》

> 一本面向中文开发者的 Rust 系统化指南：从基础到生产，入门到资深。

## 关于本书

本书覆盖 Rust 的核心理念、所有权系统、内存管理、并发编程、异步开发、性能优化、生产实践、常见问题处理、开发者技能体系，并与 C/C++/Go 进行多维度对比。每章按"基础层 → 进阶层 → 生产层"分层组织，使初学者能读懂、资深读者也能挖到细节。

- **目标读者**：有编程基础、想系统掌握 Rust 的开发者、系统工程师、嵌入式开发者
- **Rust 版本**：以 Rust 1.75+（稳定版）为主
- **写作风格**：原理 + 完整可跑代码 + 真实踩坑 + 可执行清单
- **预计篇幅**：全书 50-60k 字

## 推荐阅读路径

### 路径 A：完全新手（4 周）

```
Week 1: 01 → 03（基础层 + 进阶层）
Week 2: 04（并发基础）→ 02（深入理解所有权）
Week 3: 05（异步）→ 08（避坑指南）
Week 4: 06（性能）→ 07（生产实践）→ 11
```

### 路径 B：有 C/C++ 经验（1-2 周）

```
Day 1: 01 → 02（理解所有权的革命性）
Day 2-3: 03（语法快速过）→ 04（并发差异）
Day 4-5: 05（异步）→ 08（潜在风险）
Day 6-7: 06（性能）→ 10（对比理解）
```

### 路径 C：生产环境调优（针对性查阅）

```
06（性能） → 08（排错） → 07（生产实践） → 09（参考实现）
```

## 代码运行环境

本书代码示例基于：

```
Rust      1.75+
Cargo     1.75+
OS        Linux / macOS / Windows
```

每段可运行代码在文件头部会标注依赖。推荐使用 rustup：

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
rustup update stable
rustc --version  # 1.75.0+
```
