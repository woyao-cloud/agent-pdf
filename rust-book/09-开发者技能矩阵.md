# 第 9 章 开发者技能矩阵
> **本章导读**：Rust 开发者需要什么技能？本章从低到高划分 5 个等级，列出每个等级的核心知识、工具链、实战要求，帮助你规划成长路径。
## 1. 技能等级概览
```L1: 基础使用 ── 能跑通示例， 改动简单参数
L2: 独立开发 ── 能从 0 写项目， 处理错误， 使用基本库
L3: 生产交付 ── 能独立完成项目开发→测试→发布完整流程L4: 性能优化 ── 能解决复杂性能问题， 写底层/高性能代码
L5: 架构专家 ── 能设计系统， 制定技术选型， 带团队落地```## 2. L1: 基础使用
### 2.1 核心知识| 知识 | 掌握程度 | |------|---------| | Rust 语法 | 变量、函数、控制流 | | 所有权基础 | 移动、借用 | | 基本类型 | i32、String、Vec、Option | | 工具链 | cargo、rustc、rustup |### 2.2 技能清单
```bash# 必须会- 安装 Rust (rustup)- 编译运行 cargo run/cargo build- 理解基本错误信息- 会用基本的 match- 会用 Vec 和 String
```### 2.3 实战要求- 能用基本语法写小程序- 会用标准库文档- 能运行和修改 examples```bash
rustc hello.rs  # 编译单个文件cargo new my_project  # 创建项目```## 3. L2: 独立开发### 3.1 核心知识| 知识 | 掌握程度 | |------|---------| | 所有权系统 | 移动、借用规则 | | 生命周期 | 基本标注 | | trait 系统 | 定义、实现、约束 | | 错误处理 | Result、?、panic | | 并发基础 | thread、Mutex |### 3.2 技能清单```bash# 必须会- 构建可运行的项目（cargo new） - 管理依赖（Cargo.toml）- 编写和运行测试（cargo test）- 使用 serde 序列化/反序列化- 使用错误处理（Result、?）- 使用基本的迭代器和闭包- 使用 git 和 GitHub# 应该会- 使用 Clippy 静态检查（cargo clippy）- 格式化代码（cargo fmt）- 编写文档注释```### 3.3 实战要求- 能独立完成 CLI 工具- 能处理文件/网络 I/O- 知道何时使用 refcell/rc- 能写基本的集成测试## 4. L3: 生产交付### 4.1 核心知识| 知识 | 掌握程度 | |------|---------| | 异步编程 | async/await、tokio | | 高级 trait | 泛型约束、关联类型 | | unsafe Rust | 边界、正确使用 | | 性能优化 | 性能分析、内存布局 | | CI/CD | GitHub Actions |### 4.2 技能清单```bash# 必须会- async/await 异步编程- 使用 tokio 或 async-std- 编写性能优化代码- 使用 unsafe（保守）- 完整的测试覆盖- 交叉编译- 发布到 crates.io- CI/CD 配置# 应该会- 实现 unsafe trait- 编写过程宏- 性能调优（SIMD、LTO）- WebAssembly 编译```### 4.3 实战要求- 能完成生产级 HTTP 服务- 能正确处理高并发- 代码覆盖测试 > 80%- 发布和维护开源库## 5. L4: 性能优化### 5.1 核心知识| 知识 | 掌握程度 | |------|---------| | 编译器原理 | MIR、LLVM | | 内存模型 | 堆栈、布局、对齐 | | 并发原语 | 原子、无锁 | | 系统编程 | FFI、embedded | | SIMD | 向量化 |### 5.2 技能清单```bash# 必须会- 手动 SIMD 编程- 编写 unsafe 底层代码- FFI 调用 C 库- 嵌入式 Rust- 性能分析（perf/flamegraph）- 汇编调试- 内存优化（arena、object pool）# 应该会- 编写过程宏（procedural macros）- LLVM 优化 pass- 编写自定义allocators- 操作系统内核开发```### 5.3 实战要求- 能编写高性能库- 能做性能优化服务- 能在嵌入式平台运行- 能与 C/C++ 互操作## 6. L5: 架构专家### 6.1 核心知识| 知识 | 掌握程度 | |------|---------| | 系统架构 | 大型系统设计 | | 技术选型 | Rust vs 其他语言 | | 团队建设 | 代码规范、技术培训 | | 前沿追踪 | Rust 发展路线图 | | 开源贡献 | RFC、核心库 |### 6.2 技能清单```bash# 必须会- 设计企业级系统架构- 技术选型（何时用 Rust）- 制定编码规范- 代码审查- 性能优化- 招聘和培养 Rust 工程师- 参与 Rust 社区# 应该会- 贡献 Rust 核心- 编写 Rust 书籍- 发表技术演讲- 行业影响力```### 6.3 实战要求- 能主导企业级 Rust 项目- 能解决跨团队技术难题- 能制定技术路线图- 对 Rust 生态有影响力## 7. 工具链总览
```bash# 开发环境- rustup（版本管理）- cargo（构建/包管理）- rustc（编译器）- rustfmt（格式化）- clippy（静态检查）- rustdoc（文档）# 调试工具- lldb / gdb- perf- flamegraph- cargo-bloat# 测试- cargo test- cargo bench- cargo-fuzz- cargo-miri# 生态- tokio（异步）- serde（序列化）- clap（CLI）- actix/axum（web）- sqlx（数据库）- wasm-bindgen（WebAssembly）```## 8. 面试考点
### 8.1 基础题- 解释所有权系统- 借用和引用的区别- 生命周期是什么- Box vs Rc vs Arc- 解释 Send 和 Sync### 8.2 中级题- 解释 async/await- 线程安全 vs 数据竞争- 解释 Pin- 何时使用 unsafe- 解释 trait 对象### 8.3 高级题- 解释 Rust 编译流程- 性能优化技巧- 如何设计零成本抽象- FFI 注意事项- 解释 Rust 的内存模型## 9. 持续学习资源- Rust 官方文档：https://doc.rust-lang.org/book/- This Week in Rust：https://this-week-in-rust.org/- Rust Internals Forum：https://internals.rust-lang.org/- Rust RFCs：https://github.com/rust-lang/rfcs- Rust Blog：https://blog.rust-lang.org/
