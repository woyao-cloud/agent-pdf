# 第 2 章 核心概念
> **本章导读**：所有权、借用、生命周期是 Rust 的核心。本章详细拆解这些概念，它们是 Rust 编译期保证内存安全的关键。

## 1. 所有权系统（Ownership）
### 1.1 什么是所有权
Rust 的每个值都有一个**所有者（owner）**，当所有者离开作用域时，值被自动**释放（drop）**。

```rust
fn main() {
    let s = String::from("hello");  // s 是所有者
    // ... 使用 s ...
} // s 离开作用域，自动释放
```
这类似 C++ 的 RAII，但规则更严格。
### 1.2 移动语义（Move）
默认情况下，赋值或传递参数会导致**移动**：

```rust
fn main() {
    let s1 = String::from("hello");
    let s2 = s1;  // s1 移动到 s2，s1 不再有效
    
    // println!("{}", s1);  // ❌ 编译错误！
    println!("{}", s2);    // ✅ OK
}
```
**原因**：避免双重释放。如果 s1 和 s2 都指向同一块内存，析构时会释放两次。
### 1.3 复制语义（Copy）
对于实现了 `Copy` trait 的类型（主要是原始类型），赋值会**复制**：

```rust
fn main() {
    let x = 5;
    let y = x;  // 复制，x 仍然有效
    
    println!("x = {}, y = {}", x, y);  // ✅ 都是 5
}
```
`Copy` 类型（部分）：`i32`, `f64`, `bool`, `char`, `&T`, 元组（仅当元素可 Copy 时）
### 1.4 所有权规则
1. 每个值有且仅有一个所有者
2. 当所有者离开作用域，值被释放
3. 赋值/传参默认**移动**（非 Copy 类型）
4. 可以显式使用 `.clone()` 复制

```rust
fn main() {
    // 移动
    let s1 = String::from("hello");
    let s2 = s1.clone();  // 显式复制
    println!("{} {}", s1, s2);  // ✅ 两个都有效
}
```

## 2. 借用（Borrowing）
### 2.1 引用
不获取所有权，而是**借用**：

```rust
fn main() {
    let s = String::from("hello");
    
    // 不可变借用
    let len = calculate_length(&s);
    println!("{}", len);  // s 仍然有效
}

fn calculate_length(s: &String) -> usize {
    s.len()
}  // s 离开作用域，但不释放（因为是借用）
```
### 2.2 借用规则
1. **任意时刻**：要么一个可变引用，要么任意数量的不可变引用
2. **引用必须总是有效**（不能悬垂引用）

```rust
fn main() {
    let r;
    {
        let x = 5;
        r = &x;  // ❌ x 在内部作用域，r 引用它
    }
    println!("{}", r);  // ❌ 悬垂引用！
}
```
编译器会报错：```
error[E0597]: `x` does not live long enough
```
### 2.3 可变借用

```rust
fn main() {
    let mut s = String::from("hello");
    
    change(&mut s);
    println!("{}", s);  // "hello, world"
}

fn change(s: &mut String) {
    s.push_str(", world");
}
```
可变借用规则：**同一作用域不能同时有可变引用和不可变引用**

```rust
fn main() {
    let mut s = String::from("hello");
    
    let r1 = &s;      // 不可变
    let r2 = &s;      // 不可变（OK）
    // let r3 = &mut s;  // ❌ 可变（冲突！）    
    println!("{} {}", r1, r2);
}
```
### 2.4 借用检查器工作原理
Rust 编译器在**编译期**分析代码，确保借用规则：
- 通过**数据流分析**追踪引用的生命周期
- 检查引用的有效性（生命周期）
- 拒绝悬垂引用

> 💡 **进阶**：Rust 的借用检查器基于**NLL（Non-Lexical Lifetimes）**，比早期版本更智能，可以分析更宽的作用域。

## 3. 生命周期（Lifetime）
### 3.1 为什么需要生命周期
当函数返回引用时，编译器需要知道返回的引用**活多久**：

```rust
fn longest(x: &str, y: &str) -> &str {  // 返回哪个生命周期？
    if x.len() > y.len() { x } else { y }
}
```
编译器报错：```
error[E0106]: missing lifetime specifier
```
### 3.2 生命周期标注
使用 `'` 命名生命周期：

```rust
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() { x } else { y }
}
```
`'a` 读作"生命周期 a"，表示：
- 输入引用的生命周期
- 返回引用的生命周期
- 返回的引用至少和输入一样长
### 3.3 生命周期约束

```rust
fn main() {
    let string1 = String::from("long string is long");
    let result;
    {
        let string2 = String::from("xyz");
        result = longest(&string1, &string2);
        // result 有效到这里
    }
    // println!("{}", result);  // ❌ string2 已销毁
}
```
Rust 编译器会报错：因为返回的引用可能指向 `string2`。
### 3.4 结构体中的生命周期

```rust
struct ImportantExcerpt<'a> {
    part: &'a str,
}

fn main() {
    let novel = String::from("Call me Ishmael. Some years ago...");
    let first_sentence = novel.split('.').next().unwrap();
    
    let excerpt = ImportantExcerpt {
        part: first_sentence,
    };
}
```
结构体的生命周期 = 引用字段的生命周期
### 3.5 生命周期省略
Rust 有三条**省略规则**，编译器可以自动推断：
1. 每个引用参数有自己的生命周期
2. 如果只有一个输入生命周期，它赋给所有输出生命周期
3. 如果有 `&self` 或 `&mut self`，它赋给所有输出生命周期

```rust
// Rust 自动推断：
fn first_word(s: &str) -> &str { ... }
// 等同于
fn first_word<'a>(s: &'a str) -> &'a str { ... }
```

> ⚠️ **注意**：如果编译器无法推断，会报错要求手动标注。

## 4. 类型系统
### 4.1 静态类型 + 推断
Rust 是静态类型语言，但有强大的类型推断：

```rust
fn main() {
    let x = 42;        // 推断为 i32
    let x: i32 = 42;   // 显式指定
    let y = 3.14;      // 推断为 f64
}
```
### 4.2 泛型

```rust
fn largest<T: PartialOrd>(list: &[T]) -> &T {
    let mut largest = &list[0];
    for item in list {
        if item > largest {
            largest = item;
        }
    }
    largest
}
```
### 4.3 trait 系统
trait 类似其他语言的接口/抽象基类：

```rust
trait Summary {
    fn summarize(&self) -> String;
    // 默认实现
    fn summarize_author(&self) -> String {
        format!("({})", "Unknown")
    }
}

struct Article {
    title: String,
    author: String,
}

impl Summary for Article {
    fn summarize(&self) -> String {
        format!("{}, by {}", self.title, self.author)
    }
}
```
### 4.4 trait 约束

```rust
// 多个 trait 约束
fn notify(item: &impl Summary + Display) { ... }

// where 子句（更清晰）
fn some_function<T, U>(t: &T, u: &U) -> i32
where
    T: Display + Clone,
    U: Clone + Debug,
{ ... }
```

## 5. 智能指针
### 5.1 Box<T>（堆分配）
```rust
let b = Box::new(5);  // 堆上的 i32
println!("{}", b);    // 自动解引用
```
### 5.2 Rc<T>（引用计数）
```rust
use std::rc::Rc;

let data = Rc::new(vec![1, 2, 3]);
let clone1 = Rc::clone(&data);
let clone2 = Rc::clone(&data);
println!("{}", Rc::strong_count(&data));  // 3
```
### 5.3 RefCell<T>（内部可变性）
在不可变引用中修改数据：

```rust
use std::cell::RefCell;

let x = RefCell::new(vec![1, 2, 3]);
x.borrow_mut().push(4);
println!("{:?}", x.borrow());
```

> ⚠️ **注意**：`RefCell` 在**运行时**检查借用规则，违反会 panic。

## 6. 小结与延伸阅读
**本章重点**：
- **所有权**：每个值有唯一所有者，移动后原变量失效
- **借用**：引用不获取所有权，必须遵守规则
- **生命周期**：标注引用的有效范围，防止悬垂引用
- **类型系统**：泛型 + trait 实现代码复用
- **智能指针**：`Box`、`Rc`、`RefCell` 应对复杂场景
