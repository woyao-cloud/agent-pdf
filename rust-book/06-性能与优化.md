# 第 6 章 性能与优化
> **本章导读**：Rust 编译器的优化能力、代码级性能技巧、内存布局优化。让你写出高性能的 Rust 代码。
> 🏭 **生产层**：本章节内容直接对应生产性能要求，建议逐节精读。
## 1. 性能基础
### 1.1 Rust 性能特点
- **零成本抽象**：高级特性不牺牲性能
- **编译期多态**：泛型在编译期单态化
- **无运行时**：无 GC， 无 Ruby/Python 运行时
- **接近 C/C++**：性能同级别，可比肩或超越
### 1.2 性能测试
```rust
use std::time::Instant;
fn main() {    let start = Instant::now();        // 要测试的代码        let result = do_something();        let duration = start.elapsed();    println!("Time: {:?}", duration);    println!("Result: {}", result);}fn do_something() -> i64 {    (0..1_000_000).sum()}```## 2. 编译器优化
### 2.1 优化级别
```bash
# 开发：快速编译， 无优化
cargo build

# 发布：优化
cargo build --release

# 测试优化（用于 benchmark）
cargo test --release
```### 2.2 LTO（链接时优化）
```toml
# Cargo.toml[profile.release]lto = true  # 链接时优化， 编译慢但运行快```### 2.3 增量编译优化
```toml
# Cargo.toml[profile.dev]opt-level = 1  # 开发时也做一些优化
```### 2.4 codegen-units
```toml
# Cargo.toml[profile.release]codegen-units = 1  # 单 codegen 单元，更优优化（但编译慢）
```> 💡 **权衡**：开发时用默认配置，发布时开启 LTO + 单 codegen 单元。
## 3. 内联（Inlining）
### 3.1 内联提示
```rust
#[inline]        // 建议内联
#[inline(never)] // 禁止内联
fn hot_path() -> i32 {    // 频繁调用的函数}```### 3.2 内联层级
```rust
#[inline]           // 允许内联（默认）#[inline(always)]  // 强制内联（谨慎）#[inline(never)]   // 禁止内联
```> ⚠️ **注意**：强制内联可能增加二进制大小。
## 4. 内存布局
### 4.1 数据大小
```rust
use std::mem::{size_of, align_of};fn main() {    println!("i32: {} bytes, align: {} bytes", size_of::<i32>(), align_of::<i32>());    println!("i64: {} bytes, align: {} bytes", size_of::<i64>(), align_of::<i64>());    println!("[i32; 4]: {} bytes", size_of::<[i32; 4]>());}```### 4.2 字段重排
Rust 默认按声明顺序排列字段，可能造成填充：```rust
// 不高效
struct BadLayout {    a: i8,    // 1 byte + 7 padding    b: i64,    c: i32,}// 高效
struct GoodLayout {    b: i64,    // 8 bytes    c: i32,    // 4 bytes + 4 padding    a: i8,     // 1 byte + 7 padding}```> ✅ **最佳实践**：按大小降序排列字段，减少填充。### 4.3 repr 属性
```rust
#[repr(C)]    // C 布局（兼容 C）#[repr(packed)]  // 紧凑布局（无对齐）#[repr(align(16))]  // 对齐到 16 字节
```## 5. 迭代器 vs 循环
### 5.1 迭代器开销
迭代器在 Rust 中是零成本抽象（编译后类似手写循环）：```rust// 迭代器
fn sum_iter(v: &[i32]) -> i32 {    v.iter().sum()}// 手写循环
fn sum_loop(v: &[i32]) -> i32 {    let mut s = 0;    for x in v {        s += *x;    }    s}```
### 5.2 iter vs into_iter
| 方法 | 所有权 | 适用场景 | |------|-------|---------| | `iter()` | 不可变借用 | 读取 | | `iter_mut()` | 可变借用 | 修改 | | `into_iter()` | 消费 | 移动 |## 6. 避免动态分配

### 7.1 手动 SIMD
```rust
#[cfg(target_arch = "x86_64")]
use std::arch::x86_64::*;fn simd_add(a: &[f32], b: &[f32]) -> Vec<f32> {    let mut result = vec![0.0; a.len()];    unsafe {        for i in (0..a.len()).step_by(4) {            let a0 = _mm_loadu_ps(&a[i]);            let b0 = _mm_loadu_ps(&b[i]);            let r0 = _mm_add_ps(a0, b0);            _mm_storeu_ps(&mut result[i], r0);        }    }    result}```### 7.2 便携 SIMD（Rust 1.81+）
```rust
use std::simd::f32x4;fn simd_add(a: &[f32], b: &[f32]) -> Vec<f32> {    let mut result = vec![0.0; a.len()];    for i in (0..a.len()).step_by(4) {        let a = f32x4::from_slice(&a[i]);        let b = f32x4::from_slice(&b[i]);        let r = a + b;        r.write_to_slice(&mut result[i..]);    }    result}
```## 8. 性能分析工具
