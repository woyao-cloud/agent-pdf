# 第 3 章 基础语法与编程模型
> **本章导读**：Rust 的语法、模式匹配、错误处理和 trait 系统。掌握这些，你就能写出地道的 Rust 代码。

## 1. 基础语法
### 1.1 变量与可变性
```rust
fn main() {
    let x = 5;           // 不可变
    let mut y = 10;      // 可变
    y = 15;
    
    const MAX: i32 = 100;  // 常量（编译期确定）
}
```
### 1.2 基本数据类型
```rust
// 整数
let i: i32 = 42;
let u: u64 = 100;

// 浮点
let f: f64 = 3.14;

// 布尔
let b: bool = true;

// 字符（Unicode）
let c: char = '中';

// 元组
let t: (i32, f64, u8) = (500, 6.4, 1);

// 数组
let arr: [i32; 3] = [1, 2, 3];
```
### 1.3 函数
```rust
fn add(a: i32, b: i32) -> i32 {
    a + b  // 隐式返回（不用 return）
}

fn greet(name: &str) -> String {
    format!("Hello, {}!", name)
}
```
### 1.4 控制流
```rust
// if-else
let n = 5;
if n > 0 {
    println!("positive");
} else if n < 0 {
    println!("negative");
} else {
    println!("zero");
}

// loop + break + 标签
'outer: loop {
    loop {
        break 'outer;  // 跳出外层循环
    }
}

// while
while n > 0 {
    n -= 1;
}

// for
for i in 0..10 {  // 0 到 9
    println!("{}", i);
}
```

## 2. 模式匹配（Pattern Matching）
### 2.1 match 表达式
```rust
fn main() {
    let n = 13;
    
    match n {
        1 => println!("One"),
        2 | 3 | 5 | 7 | 11 => println!("Prime"),
        13..=19 => println!("Teen"),
        _ => println!("Something else"),
    }
}
```
### 2.2 匹配解构
```rust
struct Point { x: i32, y: i32 }

fn main() {
    let p = Point { x: 3, y: 5 };
    
    match p {
        Point { x, y: 0 } => println!("On x-axis"),
        Point { x: 0, y } => println!("On y-axis"),
        Point { x, y } if x == y => println!("On diagonal"),
        Point { x, y } => println!("({}, {})", x, y),
    }
}
```
### 2.3 Option 枚举
```rust
fn main() {
    let numbers = vec![1, 2, 3, 4, 5];
    
    // 安全的空值处理
    match numbers.get(10) {
        Some(n) => println!("Found: {}", n),
        None => println!("Not found"),
    }
    
    // 使用 if let 简化
    if let Some(n) = numbers.get(0) {
        println!("First: {}", n);
    }
}
```
### 2.4 解构元组和枚举
```rust
enum Color {
    Rgb(i32, i32, i32),
    Hsv { h: i32, s: i32, v: i32 },
}

fn main() {
    let c = Color::Rgb(255, 0, 0);
    match c {
        Color::Rgb(r, g, b) => println!("R:{}, G:{}, B:{}", r, g, b),
        Color::Hsv { h, s, v } => println!("H:{}, S:{}, V:{}", h, s, v),
    }
}
```

## 3. 错误处理
### 3.1 Result 类型
```rust
use std::fs::File;
use std::io::Error;

fn read_file(path: &str) -> Result<String, Error> {
    let mut file = File::open(path)?;
    let mut contents = String::new();
    file.read_to_string(&mut contents)?;
    Ok(contents)
}
```
- `?` 运算符：成功则展开，失败则返回错误
- 链式调用更简洁
### 3.2 自定义错误类型
```rust
use std::fmt;

#[derive(Debug)]
enum MyError {
    Io(std::io::Error),
    Parse(std::num::ParseIntError),
    Custom(String),
}

impl fmt::Display for MyError {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        match self {
            MyError::Io(e) => write!(f, "IO error: {}", e),
            MyError::Parse(e) => write!(f, "Parse error: {}", e),
            MyError::Custom(s) => write!(f, "Custom: {}", s),
        }
    }
}

impl std::error::Error for MyError {}
```
### 3.3 unwrap 和 expect
```rust
let x = Some(5).unwrap();      // 取出 Some 的值，None 则 panic
let y = Some(5).expect("msg"); // 同上，自定义错误信息

let z: i32 = "42".parse().unwrap();  // 解析失败会 panic
```
> ⚠️ **注意**：生产代码避免 `unwrap()`，使用 `?` 传播错误。

## 4. Trait 系统详解
### 4.1 定义 trait
```rust
trait Drawable {
    fn draw(&self);
    fn area(&self) -> f64 {
        0.0  // 默认实现
    }
}
```
### 4.2 实现 trait
```rust
struct Circle { radius: f64 }

impl Drawable for Circle {
    fn draw(&self) {
        println!("Drawing circle with radius {}", self.radius);
    }
    fn area(&self) -> f64 {
        std::f64::consts::PI * self.radius * self.radius
    }
}
```
### 4.3 trait 约束
```rust
// 泛型约束
fn draw_all<T: Drawable>(shapes: Vec<T>) {
    for shape in shapes {
        shape.draw();
    }
}

// where 子句
fn process<T, U>(t: T, u: U) -> String
where
    T: Clone + Display,
    U: Clone + Debug,
{
    format!("{} {:?}", t, u)
}
```
### 4.4 常用标准库 trait
| trait | 用途 | 自动派生 |
|-------|------|---------|
| Clone | 深复制 | `#[derive(Clone)]` |
| Copy | 逐位复制 | `#[derive(Copy)]` |
| Debug | 调试格式 | `#[derive(Debug)]` |
| Display | 用户格式 | 手动实现 |
| Default | 默认值 | `#[derive(Default)]` |
| PartialEq | 相等比较 | `#[derive(PartialEq)]` |
| PartialOrd | 排序比较 | `#[derive(PartialOrd)]` |
| serde::Serialize | 序列化 | serde 派生 |

## 5. 闭包（Closure）
### 5.1 闭包语法
```rust
let add = |a, b| a + b;
let add = |a: i32, b: i32| -> i32 { a + b };

// 使用闭包
println!("{}", add(3, 5));  // 8
```
### 5.2 闭包 trait
闭包自动实现以下 trait（按需要）：
- `Fn`：不可变借用
- `FnMut`：可变借用
- `FnOnce`：获取所有权

```rust
fn apply<F>(f: F) where F: FnOnce() {
    f();
}

fn main() {
    let s = String::from("hello");
    let mut count = 0;
    
    let mut inc = || {
        count += 1;
        println!("Count: {}", count);
    };
    
    apply(&mut inc);
}
```
### 5.3 闭包捕获环境
```rust
fn main() {
    let x = 4;
    
    let equal_to_x = |z| z == x;  // 捕获 x
    
    println!("{}", equal_to_x(4));  // true
}
```

## 6. 迭代器
### 6.1 基本使用
```rust
let v = vec![1, 2, 3, 4, 5];

// 消费迭代器
let sum: i32 = v.iter().sum();

// 转换
let doubled: Vec<_> = v.iter().map(|x| x * 2).collect();

// 过滤
let evens: Vec<_> = v.into_iter().filter(|x| x % 2 == 0).collect();
```
### 6.2 迭代器适配器
```rust
// map, filter, take, skip, enumerate, zip, flatten, cycle, ...
let result: i32 = (1..=10)
    .filter(|x| x % 2 == 0)      // 2,4,6,8,10
    .map(|x| x * x)              // 4,16,36,64,100
    .take(3)                     // 4,16,36
    .sum();                      // 56
```
### 6.3 自定义迭代器
```rust
struct Counter {
    current: u32,
    max: u32,
}

impl Counter {
    fn new(max: u32) -> Self {
        Counter { current: 0, max }
    }
}

impl Iterator for Counter {
    type Item = u32;
    
    fn next(&mut self) -> Option<Self::Item> {
        if self.current < self.max {
            self.current += 1;
            Some(self.current)
        } else {
            None
        }
    }
}
```
