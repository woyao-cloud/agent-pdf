# 第 7 章 生产实践
> **本章导读**：依赖管理、测试、文档、发布、CI/CD。Rust 的工具链让生产级开发更规范。> 🏭 **生产层**：本章内容直接对应生产环境，强烈建议按顺序阅读。
## 1. 依赖管理（Cargo）
### 1.1 Cargo.toml 结构
```toml[package]name = "my_project"version = "0.1.0"edition = "2021"authors = ["Your Name <you@example.com>"]license = "MIT"description = "A short description"repository = "https://github.com/..."[[bin]]name = "my_bin"path = "src/main.rs"[dependencies]serde = "1.0"serde_json = "1.0"tokio = { version = "1", features = ["full"] }[dev-dependencies]mockall = "0.11"[build-dependencies]cc = "1.0"[features]default = ["fast"]fast = []
```### 1.2 依赖版本
```toml
exact = "1.2.3"     # 精确版本^1.2.3          # 1.2.3 到 2.0.0（兼容）~1.2.3          # 1.2.3 到 1.3.0（兼容补丁）1.2.3            # 同 ^1.2.3```### 1.3 workspace
```toml# 根 Cargo.toml[workspace]members = ["crate_a", "crate_b"]resolver = "2"# crate_a/Cargo.toml[package]name = "crate_a"
version.workspace = true  # 继承版本```
### 1.4 Cargo.lock
- 锁定所有依赖版本
- 提交到版本控制
- 确保构建可重现
```bash
# 更新依赖
cargo update
cargo update -p serde  # 更新特定包```## 2. 测试

```rust
// benches/bench.rs
use criterion::{black_box, criterion_group, criterion_main, Criterion};fn fibonacci(c: &mut Criterion) {    c.bench_function("fib 20", |b| b.iter(|| fib(black_box(20))));}fn fib(n: u64) -> u64 {    match n {        0 => 0,        1 => 1,        _ => fib(n - 1) + fib(n - 2),    }}criterion_group!(benches, fibonacci);criterion_main!(benches);```运行：```bash

### 7.1 Result vs panic
| 场景 | 处理方式 | |------|---------| | 可恢复错误 | `Result` | | 逻辑错误 | `panic!` / `assert!` | | 预期失败 | `Option` | | 调试时 | `unwrapped` / `expect` |
### 7.2 错误链
```rust
use std::io;use std::fmt;#[derive(Debug)]enum MyError {    Io(io::Error),    Parse(std::num::ParseIntError),    Custom(String),}impl fmt::Display for MyError {    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {        match self {            MyError::Io(e) => write!(f, "IO error: {}", e),            MyError::Parse(e) => write!(f, "Parse error: {}", e),            MyError::Custom(s) => write!(f, "Custom: {}", s),        }    }}impl std::error::Error for MyError {}impl From<io::Error> for MyError {    fn from(e: io::Error) -> Self {        MyError::Io(e) }}```## 8. 小结
