# 第8章 测试驱动开发
## 8.1 TDD 实践
测试驱动开发（Test-Driven Development，TDD）是一种软件开发方法论，其核心思想是先编写测试，再编写实现代码。Claude Code 内置了 TDD 引导功能，帮助你实践 TDD。
### 8.1.1 测试优先原则
**TDD 流程**```mermaidgraph LRA[红色阶段] --> B[编写失败的测试]B --> C[绿色阶段]C --> D[编写最小实现使测试通过]D --> E[重构阶段]E --> A[下一轮]```**三定律**1. **第一定律**：在编写任何生产代码之前，必须编写一个失败的测试
2. **第二定律**：只编写足够使测试通过的最少量代码
3. **第三定律**：重构代码以消除重复**使用 Claude 进行 TDD**
```bash# 启动 TDD 会话
claude "用 TDD 方式开发一个用户认证模块"```Claude 会引导你：1. 先描述要实现的功能
2. 编写测试用例
3. 运行测试（失败）
4. 编写最小实现5. 运行测试（通过）
6. 重构优化### 8.1.2 测试用例设计
**好的测试用例特征**- **独立性**：每个测试用例独立运行，不依赖其他测试- **可重复性**：每次运行结果一致- **清晰的意图**：测试名称清晰表达测试内容- **单一职责**：每个测试只验证一个行为**测试命名规范**```python
# 不好的命名

### 8.4.1 完整 TDD 流程示例**任务**：实现一个计算器的基本功能```bash

# calculator. py
class Calculator:    def add(self, a, b):        return 5```运行测试：PASS**第三步：添加更多测试**```pythondef test_add_negative_numbers():    calc = Calculator()    result = calc.add(-1, -2)    assert result == -3def test_add_with_zero():    calc = Calculator()    result = calc.add(5, 0)    assert result == 5```**第四步：完善实现**```pythonclass Calculator:    def add(self, a, b):        return a + b```**第五步：重构**```python
from typing import Unionclass Calculator:    def add(self, a: Union[int, float], b: Union[int, float]) -> Union[int, float]:        """返回两个数的和。        Args:            a: 第一个数            b: 第二个数        Returns:            两数之和        """        return a + b    def subtract(self, a: Union[int, float], b: Union[int, float]) -> Union[int, float]:        """返回两个数的差。        """        return a - b    def multiply(self, a: Union[int, float], b: Union[int, float]) -> Union[int, float]:        """返回两个数的积。        """        return a * b    def divide(self, a: Union[int, float], b: Union[int, float]) -> Union[int, float]:        """返回两个数的商。        Raises:            ZeroDivisionError: 当除数为零时        """        if b == 0:            raise ZeroDivisionError("Cannot divide by zero")        return a / b```### 8.4.2 测试组织结构**推荐的项目结构**```project/
