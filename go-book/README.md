# 《精通 Go》

> 一本面向中文开发者的 Go 系统化指南：从基础到生产，入门到资深。

## 关于本书

本书覆盖 Go 的核心理念、核心语法、并发编程、网络编程、性能优化、生产实践、常见问题处理、开发者技能体系，并与 Python/Java/C++ 进行多维度对比。每章按"基础层→进阶层→生产层"分层组织，使初学者能读懂、资深读者也能挖到细节。

- **目标读者**：有编程基础、想系统掌握 Go 的开发者、后端工程师、云原生开发者
- **Go 版本**：以 Go 1.21+（稳定版）为主
- **写作风格**：原理 + 完整可跑代码 + 真实踩坑 + 可执行清单
- **预计篇幅**：全书 50-60k 字

## 推荐阅读路径

### 路径 A：完全新手（3 周）

```
Week 1: 01 → 03（基础层）
Week 2: 04（并发）→ 06（标准库）
Week 3: 05（网络）→ 09（避坑）→ 11
```

### 路径 B：有其他语言经验（1 周）

```
Day 1: 01 → 02（快速过语法）
Day 2-3: 04（并发核心）→ 05（网络）
Day 4-5: 07（性能）→ 09（潜在风险）
Day 6-7: 10（技能矩阵）→ 11（对比）
```

```
07（性能） → 09（排错） → 08（生产实践） → 10（参考实现）
```

## 代码运行环境

本书代码示例基于：

```
Go       1.21+
OS       Linux / macOS / Windows
```

推荐使用 Go 安装：

```bash
# macOS / Linux
brew install go

# Windows
# 下载安装包 https://go.dev/dl/

# 验证
go version  # go1.21+
```
