# 第 2 章 核心语法与类型系统
> **本章导读**：Go 的基础语法、数据类型、接口、切片和映射。掌握这些，你就能写出地道的 Go 代码。
## 1. 基础语法
### 1.1 变量声明
```go
// 方式一：类型推断
var name = "Go"

// 方式二：显式类型
var name string = "Go"

// 方式三：短声明（函数内）
name := "Go"

// 常量
const Pi = 3.14159
const (
    StatusOK = 200
    StatusNotFound = 404
)
```
### 1.2 基本数据类型
```go
// 整型
var i int = 42
var ui uint = 42
var f float64 = 3.14
var b bool = true
var s string = "hello"
var c complex128 = complex(1, 2)

// 字节和字符
var byteVal byte = 'A'
var runeVal rune = '中'  // Unicode
```
### 1.3 控制流
```go
// if-else
if x > 0 {
    fmt.Println("positive")
} else if x < 0 {
    fmt.Println("negative")
} else {
    fmt.Println("zero")
}

// switch（不需要 break）
switch day {
case "Mon":
    fmt.Println("Monday")
case "Tue", "Wed":  // 多值
    fmt.Println("Tuesday or Wednesday")
default:
    fmt.Println("Other day")
}

// for（Go 只有 for 循环）
for i := 0; i < 10; i++ {
    fmt.Println(i)
}

// 无限循环
for {
    // 需主动退出
    break
}

// range 遍历
for i, v := range slice {
    fmt.Println(i, v)
}
```
## 2. 数组与切片
### 2.1 数组
```go
// 固定长度
var arr [5]int
arr[0] = 1

// 初始化
arr := [5]int{1, 2, 3, 4, 5}

// 多维数组
matrix := [2][3]int{
    {1, 2, 3},
    {4, 5, 6},
}
```
### 2.2 切片（Slice）
```go
// 切片是数组的视图
s := []int{1, 2, 3, 4, 5}

// make 创建
s := make([]int, 5)      // 长度5，容量5
s := make([]int, 0, 10)  // 长度0，容量10

// 子切片
s := []int{1, 2, 3, 4, 5}
s1 := s[1:3]  // [2, 3]
s2 := s[:3]   // [1, 2, 3]
s3 := s[2:]   // [3, 4, 5]

// append 扩容
s = append(s, 6)
s = append(s, 7, 8, 9)

// copy
copy(dst, src)
```
> ⚠️ **注意**：切片是引用类型，复制切片只是复制了指针。
```go
// 错误示例：共享底层数组
s1 := []int{1, 2, 3}
s2 := s1[:2]
s2[0] = 99
fmt.Println(s1)  // [99, 2, 3] - s1 也被修改！
```
## 3. 映射（Map）
### 3.1 创建和使用
```go
// 创建
m := make(map[string]int)
m := map[string]int{
    "apple":  1,
    "banana": 2,
}

// 赋值
m["orange"] = 3

// 读取
v, ok := m["apple"]  // ok 表示是否存在

// 删除
delete(m, "banana")

// 遍历
for k, v := range m {
    fmt.Println(k, v)
}
```
> ⚠️ **注意**：map 是无序的，每次遍历顺序可能不同。
## 4. 结构体与方法
### 4.1 结构体
```go
type Person struct {
    Name string
    Age  int
    Email string
}

// 创建
p := Person{
    Name:  "Alice",
    Age:   30,
    Email: "alice@example.com",
}

// 指针
p := &Person{Name: "Bob"}

// 访问字段
fmt.Println(p.Name)
fmt.Println(p.Age)
```
### 4.2 方法
```go
type Person struct {
    Name string
    Age  int
}

// 值接收者
func (p Person) Greet() string {
    return fmt.Sprintf("Hello, I'm %s", p.Name)
}

// 指针接收者（可修改对象）
func (p *Person) Birthday() {
    p.Age++
}

// 使用
p := Person{Name: "Alice", Age: 30}
fmt.Println(p.Greet())
p.Birthday()
```
## 5. 接口
### 5.1 接口定义
```go
type Reader interface {
    Read(p []byte) (n int, err error)
}

type Writer interface {
    Write(p []byte) (n int, err error)
}

// 接口组合
type ReadWriter interface {
    Reader
    Writer
}
```
### 5.2 空接口
```go
// 空接口可以接受任何值
var i interface{} = 42
var s interface{} = "hello"
var m interface{} = map[string]int{"a": 1}

// 类型断言
v := i.(int)
v, ok := i.(int)  // 安全断言

// type switch
switch v := i.(type) {
case int:
    fmt.Println("int:", v)
case string:
    fmt.Println("string:", v)
default:
    fmt.Println("unknown")
}
```
> ✅ **最佳实践**：使用接口实现多态，依赖抽象而非具体。
## 6. 类型系统
### 6.1 类型定义
```go
// 类型别名
type MyInt = int

// 类型定义（新类型）
type Age int

func (a Age) IsAdult() bool {
    return a >= 18
}
```
### 6.2 泛型（Go 1.18+）
```go
// 泛型函数
func Sum[T int | float64](nums []T) T {
    var sum T
    for _, n := range nums {
        sum += n
    }
    return sum
}

// 使用
fmt.Println(Sum([]int{1, 2, 3}))       // 6
fmt.Println(Sum([]float64{1.1, 2.2}))  // 3.3

// 泛型类型
type Pair[K any, V any] struct {
    Key   K
    Value V
}
```
### 6.3 内置类型约束
```go
// comparable（可比较）
func Contains[T comparable](s []T, v T) bool {
    for _, item := range s {
        if item == v {
            return true
        }
    }
    return false
}
```
